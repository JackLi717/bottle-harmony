# 当前倒水画面与声音契约

涟漪、轮廓、完成柔光、瓶塞细节、分组水声与倒水辅助符号均已实现。本文维护当前时间线与取消契约；版本／公开配置见[基线](current-baseline.md)，实际设备验收见[设备支持](device-support.md)，不保留逐次修复流水。

## 几何与时间线

- 十五种容器统一棋盘款式，保持真实内腔、等体积四份、液面与瓶口连接，高脚杯杯脚不盛水。逻辑先提交，表现不授予进度。
- 倒水总时长 1900 ms，声音只覆盖约 0.769 秒可见水流。保持现有移动／回位时长，允许移动瓶横向越界裁切。
- 三道涟漪与落点凹陷亮边跟随目标液面并受杯腔裁切；扩散中段最清晰，明暗双边，接水时压低静态高光。断流不再起新波，衰减 210 ms，与回位重叠。
- 提瓶、移向目标与回位使用局部轮廓；完成瓶使用本色柔光，窄口瓶塞贴合／反光，宽口杯光晕。整局柔光 620 ms 与礼花开场重叠，不增加等待。
- 静止与倾倒符号共用液层几何，世界坐标保持正向，按实际层内空间缩放、薄层淡出；满杯同色视觉装满后沿既有时间线 180 ms 淡出，混色仍显示，撤销恢复。完整规则见[游玩流程](play-flow.md#视觉与内部工具)。

## 音频契约

十五款容器映射六类、十八段 CC0 实录；目标起始水位为空／一两份／三份时选 low／mid／high，多份连续倒水只播一条。映射、来源、处理、许可及哈希由[音频说明](../assets/audio/README.md)和[manifest](../assets/audio/pour/manifest.json)维护。

当前音色类三个播放器在等待操作时提前加载、静默准备与回零；有界检查原生就绪状态。可见出水开始时若未准备好，本次静音；加载迟到或中途解除静音不补播。旧异步回调在取消／卸载后失效，准备不能依赖 RN 侧上一轮末尾的动画值。

十八段为试听代理，没有标定虚构容器或实际接收水位；low／mid／high 是同来源不同时刻的剪辑。保持原速原音高，保留来源记录；是否替换录音由手机试听决定，不宣称精确物理模拟。

声音与礼花共用本地开关；切后台、返回、撤销、重来、窗口变化及减少动态效果沿用统一取消规则。音频失败不影响逻辑状态。Android 原生点击声由系统设置控制，不加应用点击开关。

## 验收

覆盖全部十五款、空／半满／近满接水、单份／多份、左右／跨排／边缘倒水、完成及撤销恢复。几何与声音回归检查映射、时长、首尾、削波、来源哈希、取消和加载超时。真机扬声器／耳机同步、连续重复疲劳及低端性能仍需验收，见[设备支持](device-support.md)。
