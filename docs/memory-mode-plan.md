# 观察记忆玩法规划

状态：2026 年 10 月 8 日，用户已授权按规划扩充至 100 题。`memory-100-v1` 已通过专门离线程序制作并接入源码，iPhone 开发签名 Release 已覆盖安装并启动；尚未商店发布。本文是记忆专题的唯一正文；[颜色解锁专题](color-unlock-plan.md)仍为后续候选。M 等级和恢复效果是制作假设，尚待真人校准。

## 体验目标与首批边界

玩家先看完整棋盘，主动开始后记住被遮住的颜色位置，再结合逐步揭示的信息完成整理。希望产生“我记得它在这里”的判断与验证感，同时允许探索和恢复。

建议首批采用自主观察、部分下层遮色、顶段始终可见、游玩中新揭示信息保留的温和规则。记忆负担与整理难度分开增加。不开强制观察倒计时，不隐藏整个瓶子，不把错误记忆设为扣生命、收费或限次重试，也不与锁瓶、凝固、变容量或十八瓶一起推出。

严格限时记忆、撤销后重新遮色、从未展示过底色的纯探索均为不同规则候选，不混入首批等级。原型使用独立入口、关号和进度，四区域归属及正式权益后定。

## 观察、揭示与恢复规则

| 时刻或动作 | 建议行为 |
| --- | --- |
| 首次进入尝试 | 完整展示实际颜色与辅助符号；玩家点“准备好了”进入倒水阶段，观察时不能移动液体 |
| 进入倒水阶段 | 按该题固定遮色方案隐藏部分下层的颜色及符号；液量、瓶位、层数和空瓶保持可见 |
| 顶部可操作信息 | 输入前显露每瓶最大连续同色顶段，保证玩家知道倒出的颜色和数量；目标顶色与余量可判断 |
| 新露出的层 | 移走上层后显露新的同色顶段；游玩中揭示的液体信息在本次尝试内永久保留 |
| 液体移动 | 已显露液体随倒水保持已知；同色液体不因混合而重新隐藏 |
| 撤销 | 恢复液体和历史，但保留本次尝试已经揭示的信息；不删除实际倒水、查看和撤销记录 |
| 重来 | 回到原排列与完整观察阶段，重新建立本次尝试的揭示集合；之前尝试计入累计，题目不换 |
| 再看一眼 | 暂时展示当前棋盘全部颜色，倒水暂停；玩家关闭后回到既有遮色状态，不把临时查看变成永久揭示 |
| 后台或返回 | 暂停并恢复原观察／倒水／查看阶段；不能借切后台、重开页面或冷启动自动获得一次完整展示 |
| 完成与重玩 | 完成反馈可展示全部颜色；重玩建立新尝试并重新观察，记录为已经玩过的题 |

“初始完整看过”“临时查看过”“游玩中永久揭示”必须分别表示。若把开局展示算入永久揭示集合，点准备后就无法遮色。临时查看次数在成功展示时记录，重复点击或恢复同一查看界面不重复累计。

底色可以遮住，但合法动作的直接条件必须可见。当前规则会一次倒出最大同色顶段，不能只展示最顶一层却突然倒出多份隐藏液体；每次局面变化先显露完整顶段，再接受下一次输入。遮色位置只影响信息，不改液量、最大倒水规则或完成条件。

原型中撤销、重来、再看一眼和按需一步提示免费，不消耗正式主线资源，也不发主线奖励。一步提示使用完整真实局面，是额外帮助，记录实际执行；不能把“未重新查看”表述成“未使用任何帮助”。正式查看／提示资源、Premium 和推荐关系在选择实施前冻结，不默默减少无限一步提示权益。

## 游戏界面

沿用现有深色背景、玻璃器皿、液体配色和轻点倒水。观察、整理、临时查看和完成使用同一个棋盘区域，切换阶段不改变瓶位或瓶子尺寸。原型入口与进度独立；棋盘页只显示关号，不显示“观察记忆”标题，返回后继续原阶段。

| 状态 | 信息与视觉 | 主要操作 |
| --- | --- | --- |
| 入口 | 首页沿用现有容器展示，增加“颜色记忆”眼睛按钮；进度独立 | 开始／恢复当前记忆题 |
| 首次教学 | 首次开始玩法时独立显示一屏教学：观察带虚线标记的液体层、准备后遮色、边整理边揭示；用同一只瓶的前后对照说明，不计时，可再看 | “知道了，开始”；完成后记住教学已完成，不再自动显示 |
| 开局观察 | 完整棋盘；在本题将遮色的每一份液体上画浅金色虚线框，实际颜色与辅助符号仍可见；不显示阶段栏、逐题教学句或点名瓶位 | 底部大眼睛图标与“准备好了”；观察时不能倒水，点击后收成右侧第四个工具按钮 |
| 整理 | 未知液体使用统一中性灰，保留实际液量、每份边界与问号，隐藏原色及辅助符号；已知液体保持原有颜色，不增加状态栏 | 底部同一排依次为撤销／提示／重来／查看；最右侧眼睛按钮随时进入完整查看，不另占一行 |
| 临时完整查看 | 原地恢复当前棋盘的全部颜色；查看次数用简短计数表达，无阶段栏和自动关闭倒计时 | 最右侧同一按钮改为“整理”与划线眼睛图标；点击后收起查看，倒水、撤销、提示暂停，重来可返回开局观察 |
| 完成 | 完整展示已整理棋盘，沿用器皿完成视觉；结果直接留在棋盘上，不另盖成绩卡或评定记忆能力 | 庆祝结束后“下一题”，第一百题后“再玩一轮”；辅助次数保存在本地统计 |

棋盘页顶部只放返回与关号，不增加模式名称、“观察中／整理中／完整查看中”状态栏或逐题教学文案，保持与现有游戏界面一致。底部预留主操作与反馈空间，观察时隐藏工具但保留占位，避免进入整理后棋盘上下跳动。开局的大眼睛按钮点击一次后缩为工具栏最右侧第四项；此后“查看／整理”始终原位切换，不再出现独立的整行查看按钮，四项工具保持相同点击尺寸。进入下一题或重来回到开局观察时，再显示大的“准备好了”按钮，不重播首次教学；查看次数单独记录在辅助事实中。选中瓶沿用抬起与局部描边；成功倒水揭示的新颜色只做短暂强调，撤销后仍保留，不弹提示链。

遮色标记对应具体液体份额与固定遮色方案，不标记某种颜色在整盘中的全部出现位置，也不用瓶旁的小点代替层位范围。虚线框描边留在液体内部，不盖住颜色或符号；点击“准备好了”时，同一位置移除标记并替换为中性遮色。顶部最大同色段的强制可见规则优先：若某份开局就必须显露，则不标成即将遮色。标记是每题的观察信息，持续提供；说明标记含义的文字只在首次教学显示。临时再看不重新加入开局标记，也不恢复逐题教学。

教学完成标志作为本地偏好与棋盘尝试分开保存，只在点击“知道了，开始”后记为完成。未完成教学时，切后台恢复原教学，返回入口后再开始仍显示教学；完成后下一题、重来、回入口和重启都不自动重播。应用已将教学完成标志存入 SQLite 独立偏好；交互稿只用于界面参考。

遮色采用不透明、无原色倾向的液体填充，不能用半透明蒙层或模糊泄露色相。问号表示未知信息，不使用凝固关的冰裂纹，也不让人误以为液体不能倒。连续同色顶段按规则整体显露，问号不代替可操作顶色。读屏从上到下描述可见颜色与“未知颜色”、液量及余量；关闭符号、切器皿或恢复页面不额外揭示颜色。

四至十二瓶继续采用同屏统一大瓶尺寸、全宽两排、每排最多六瓶；八瓶示例只增加列数，不缩小同屏瓶子。小屏优先减少纵向装饰间距，保留可读文字和至少 44 点操作区域；横屏与大屏沿用现有布局策略。原型免费辅助规则不通过金币、锁或付费弹层表现。

[交互界面稿](previews/memory-interface.html)覆盖首次教学、入口、观察、整理、再看及完成，并支持六瓶／八瓶密度和辅助符号预览。示例底题已用现有求解器验证可解；示例排列与颜色置换仅用于界面评审，不计入百题题库。界面稿不接入应用、SQLite、正式进度或权益；实际应用已接入倒水与完成表现；设备验收边界见下文。

## 出题策略

一题由“已验证的普通棋盘 + 固定遮色方案 + 可见性规则版本”组成。记忆玩法先使用较容易的整理结构，让记住位置产生价值，再逐步引入需要跨几次操作保留的信息。

| 题型 | 考察内容 | 出题重点 |
| --- | --- | --- |
| 单点定位 | 记住一只瓶下方的目标色 | 隐藏信息少，揭示后很快形成合并 |
| 两瓶配对 | 记住相同颜色分散在哪两处 | 有清楚的对应关系，不靠相近色混淆 |
| 底层顺序 | 记住一瓶下方两层的顺序 | 顺序确实影响下一段整理，不只是多遮两格 |
| 跨瓶关联 | 释放一处颜色时，记得另一处的去向 | 一次增加关联数量，底层整理仍宽松 |
| 延后使用 | 经过几步熟悉操作后再利用先前信息 | 用动作间隔衡量延迟，不用强制等待制造难度 |
| 记忆与推断 | 将记住的信息与颜色总量结合 | 单独标注可推断线索，不把所有成功归因于记忆 |

不要求每题都让记错导致死局。优先让准确记忆减少无目的探索、查看或绕路；恢复仍然自由。重绘、瓶子形状切换或动画不应改变实际排列，开局观察后不洗牌。

### 候选制作与验收链路

1. 先生成普通四层、颜色守恒且无初始完成瓶的底题，完整求解和路线回放。第一批维持初始每瓶同色最多两层，避免靠三层同色快速自动揭示大部分答案。
2. 按题型选择底部一层或两层遮色，应用完整顶段显露规则后，计算真正仍被遮住的数量；不拿配置中的遮色格数冒充实际负担。
3. 回放解法并追踪各液体单位及其可见性，记录何时揭示、揭示前经过多少有效倒水、哪些已知位置需要关联；至少审阅一条不同路线，避免只适配参考解法。
4. 建立同规模的完全可见对照和不同遮色强度对照，观察记忆版本新增了什么判断。相同底题的多种遮色方案归为题目变体，不宣称它们是不同物理谜题。
5. 小规模原型可构造两道公开可见部分相同、隐藏安排不同且都守恒可解的题，完整求解比较下一步最佳取舍是否不同。用来验证记住隐藏信息可能有实际价值，不要求所有题都是这种陷阱。
6. 独立验证底题来源、路线、遮色约束、顶段显露、知识随移动／撤销传播及恢复；再人工检查信息可读性与记忆价值，完成去重后才进入试排。

每道题保存实际底题、固定遮色方案和来源，不在手机按随机遮色临时决定难度。改色或换瓶位不算新底题；物理结构与遮色结构分别去重、统计。评估记忆差异时可允许有目的的匹配变体，但不能连续安排同底题让熟悉度代替新体验。

## 难度考察

整理和记忆采用两个维度，不先相加为一个未经验证的 0–100 分。底题可在现有范围内离线计算普通 `human-decision-v1` 对照分；它不包括遮色，不能作为记忆模式评级。记忆初期先使用原始量与独立 M1–M4 制作等级。

| 维度 | 记录内容 | 用途与边界 |
| --- | --- | --- |
| 整理负担 | 空瓶、普通代理、最短步数、准备与选择后果 | 判断玩家是否因普通解谜而卡住 |
| 初始遮色量 | 顶段显露后的隐藏份数 H、涉及瓶数 HB、涉及颜色数 HC | 三者分别看；隐藏格多不必然需要记得多 |
| 遮色深度 | 每瓶底部一层／两层、深浅分布 | 区分位置关联与层序负担 |
| 关联范围 | 同色跨瓶对应、需要协调的位置、可由总量推断的线索 | 先人工标注并附例，不宣称已证明记忆必需 |
| 延迟与揭示 | 各隐藏单位首次揭示前的有效动作数、揭示进度曲线 | 只描述被审阅路线，不等于人的记忆保存时长 |
| 辅助与探索 | 再看、实际提示、撤销、重来及揭示速度 | 使用帮助不是失败；多次探索不直接判记忆差 |
| 识别条件 | 颜色数、符号、容器、屏幕与可读性 | 小屏色差造成的困难不算记忆挑战 |

开局观察时长与完整查看时长分开记录，后台不计；解题时间采用前台可操作口径，动画、礼花、覆盖界面等按[统计方案](gameplay-statistics-plan.md)处理。观察时间更长不自动代表题更难或玩家更弱。

不承诺训练效果或“记忆力分数”。通关反馈可显示实际查看／提示次数与完成状态；未查看通关也可能包含探索和撤销，不能称为纯记忆完成。

## 颜色、瓶数与遮色增长

第一批保持两只完全可用空瓶 E=2，每色四份，总瓶数 B=C+2；空间政策先固定，避免同时减少空间和增加记忆负担。H 为开始倒水时真正隐藏的份数，HB 为涉及瓶数；表中范围还须满足底部遮色与顶段可见条件。

| 当前内容段 | 实际颜色 C／总瓶数 B | 实际 H／HB | 每瓶遮色 |
| --- | --- | --- | --- |
| 1–3 教学 | 2–3／4–5 | 1–2／1–2 | 底部一层 |
| 4–10 入门 | 3–4／5–6 | 2–4／2–4 | 底部一层 |
| 11–20 发展 | 4–5／6–7 | 3–6／2–4 | 从第 14 题引入两层 |
| 21–30 关联 | 5／7 | 4–8／3–4 | 至多两层 |
| 31–60 扩展 | 5–6／7–8 | 6–10／3–5 | 至多两层 |
| 61–100 综合 | 6–8／8–10 | 8–12／4–6 | 至多两层 |

上述为交付内容的实际范围，包含恢复题。第 11–12、21–22 题故意低于原增长区间的 H 下限，承接前一挑战。全组恰好两个空瓶；H≤2×HB、HB≤min(C,6)，每瓶从底部连续遮一或两层，禁止遮到开局最大同色顶段。只有八题使用八色／十瓶；六色题四十道，七色题二十道，不靠无限增加棋盘制造难度。

增加颜色会同时影响辨认和关联，增加瓶数会影响位置查找，增加 H 会影响待记信息。因此同一过渡只提高一项主要负担：先在三四色情况下增加遮色，再引入第五色，降低遮色巩固，然后恢复原负担。大棋盘未必比小棋盘更难。

若未来仍保持 E=2，十二瓶最多十色。单空瓶、三层遮色、更多颜色或十八／二十四瓶属于后续独立检验，不作为首批必然升级终点。现有十五款外观全部免费、统一选择；不通过换陌生瓶形、缩小色层、移位或解锁外观制造记忆难度。底题逻辑只有普通四层瓶。

## 分级与坡度

| 制作等级 | 记忆特点 | 整理控制 |
| --- | --- | --- |
| M1 认识 | 1–2 个单点，看到后较快验证 | 容易整理、少分支 |
| M2 定位 | 多瓶位置或简单配对，底部一层为主 | 保持宽松空间，不同时增加规划 |
| M3 关联 | 部分两层顺序、跨瓶关联或延后使用其中一项 | 用熟悉底题结构承载新负担 |
| M4 综合 | 两种已学信息关系组合，仍可自由再看 | 适度整理选择，避免高规划与高记忆同时封顶 |

M 等级不是隐藏份数分档。同样 H=6，六个很快露出的单点与三只瓶中需延后使用的层序可能不同；须由具体证据与试玩判定。第一批的重点是 M1–M3，M4 少量验证。

百题采用十个十题单元：位置 1–2 恢复／巩固、3–5 单因素爬坡、6 次峰、7 恢复、8–9 组合爬坡、10 主峰；首单元前三题教学。

| 单元 | 熟悉区间 | 次峰／主峰目标 | 下一单元恢复 |
| --- | --- | --- | --- |
| 1–10 | M1，开始 M2 定位 | 小配对／多位置 M2 | 减少隐藏位置，保留熟悉颜色 |
| 11–20 | M2，开始 M3 的一种关系 | 单一层序或延迟／M3 | 减少 H 或取消层序，保持底题容易 |
| 21–30 | M2–M3 | M3／少量 M4 | 若继续扩充，回到已熟悉的单一关系 |

恢复采用至少降低一个等级，或在同级内明显减少隐藏量／关联／延迟中的一项，并由试玩确认放松；单纯增加查看额度不代表题目本身已经缓冲。颜色数与普通底题规划不在记忆峰上同时加码。主峰规划目标不下降，普通题允许回落；不套用普通主线的分差阈值。

每题记录整理操作量与颜色段数、M 制作等级、角色、H／HB／HC、遮色深度、主考察关系和相邻变化；本批不计算普通主线代理分或宣称真人难度。若查看次数突然上升，先判断是记忆、整理还是识色造成；不自动压缩观察时间或削减辅助。

实际排题先固定各单元的底题整理区间和主考察关系，选定次峰／主峰，再找恢复题，最后填入爬坡。非教学段新增颜色最多加一色，优先放在位置 3 并降低遮色，位置 4–5 巩固；一层到两层遮色也单独引入，保持颜色与隐藏总量相近。单次增加 H 先以一至两份为试验步幅；与 HB 必然联动的变化记为一次信息量增长，不能再同时加颜色、层序或延迟。位置 8–10 组合已熟悉因素。

验收逐个过渡检查新增信息、揭示曲线、底题整理稳定性与恢复，再连续试玩十题。候选的 H 很高但迅速全部揭示，不能代替记忆峰；同级题的实际负担不同，按反馈重排。供给不足时缩短题集，不放松可见性规则凑数；若以后扩充到四百题，优先增加配对、层序和延迟结构的变化，规模上限保持十二瓶，不无限叠加遮色或颜色。

## 百题制作与验证

专门程序 `scripts/memory-bank.ts` 按 `memory-ten-wave-v1` 配方生成，离线输入为 `assets/levels/memory-100.json`。运行只读 `content.sqlite`，不会在手机现场生成、挑选遮色或评级。

```sh
npm run memory:build
npm run memory:verify
npm run content:build
```

- 95 道新底题来自可直接寻址、可重建的全打乱／单底色混排生成器；保留原五道测试题的布局、颜色、瓶 ID、遮色与题目 ID，分别排为 1、2、14、10、20。现有 SQLite 尝试按稳定题目 ID 恢复，重新编号不重置当前棋盘、永久知识、撤销或教学。
- 全部 100 道物理结构互异，重命名颜色、交换瓶位不算新题。遮色结构另统计为 26 种图样，允许复用熟悉图样；完全可见和较轻遮色只作为同底题对照变体，不额外计题。
- 每题完整求解，独立来源重建与路线回放；另存不同起始出水瓶的完整解法，排除只交换空瓶位置的伪变化。必需求解未知不入库，时间超限终止制作，失败保留已有输出。
- 两条路线分别重算各隐藏单位首次揭示动作、剩余隐藏曲线及延迟，验证整段顶色显露、稳定液体身份、永久知识、撤销及恢复。M3 至少有不同颜色的两层顺序；M4 同时有层序、跨瓶同色关联，并且两条路线均存在至少八次倒水后的首次揭示。推断题标明颜色守恒可确定至少两份剩余未知色的具体路线位置；推断和记忆贡献不混称。
- 主峰 H 目标为 4、6、8、8、9、10、10、11、12、12；M 制作等级分布为 M1／M2／M3／M4 = 4／13／36／47。不是按 H 自动评分；恢复至少降低 M 等级或 H，同色数恢复题的参考整理操作量不超过对应挑战。
- 新增颜色最多一色，增加颜色时不同时增加 H；单次 H 增加最多两份。第 33、73、93 题增色时仍保持 M3，随后再组合已学因素。相邻操作量及揭示变化输出到 `builds/memory-100-report.json`，用于逐题审阅，不声称真人压力单调。
- SQLite 导出后核对 100 题实际布局、遮色、双路线与完整证据，并验证完整性、外键及 SHA-256；原 1000 主线／50 副关仍逐项读回，不改其内容或钱包规则。

本批参考解法为 7–26 次倒水。自由观察、免费查看／提示／撤销／重来继续保留；难度不靠定时、限次帮助或减少空瓶实现。题型名称表示制作目的；即使存在层序、关联和延迟，也不证明记忆是必需或比探索更有效。

## 试玩校准

后续重点是记忆是否帮助决策、层序与关联是否清楚、恢复题是否放松，以及普通整理或识色是否抢走注意力。建议招募 6–10 名不同熟悉程度的试玩者，记录观察、查看、提示、撤销、重来、首次揭示与主观反馈；人数和完成事实如实报告，不作训练效果或留存结论。

使用规模相近的完全可见题和较轻遮色变体作对照，交叉分配，避免先玩同底题产生熟悉度污染。若总在逐瓶试探，调整隐藏信息对选择的实际作用；若记得颜色仍卡住，降低底题整理负担。自动证据不能代替这些反馈。

十五款容器、小屏符号／读屏、真实水声与帧率、前后台恢复和 TV 连续遥控仍须按设备验收。商业资源、四区域映射、严格限时记忆、颜色解锁及组合机关均未因百题制作自动启用。
