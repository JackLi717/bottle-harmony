# 颜色记忆玩法

状态：2026 年 10 月 9 日，按用户确认的黑色万能块规则落地，百题为 `memory-100-v2`，规则为 `memory-black-v1`。本文是记忆规则、题库制作和实现边界的唯一正文。主线、副关、钱包及商业权益不随此玩法改变；尚无玩家测试，M 等级与趣味性仍需真人校准。设备安装和实际验收见[设备记录](device-support.md)。

## 目标与明确规则

玩家先看完整棋盘，记住带标记的份额，再将持续隐藏的黑色块按记忆整理，整理到外观完成时自动揭晓验证。黑色块即使露到顶部、倒出或移动到位也不自动显色；真实颜色始终固定，结算时不能任意变色。取消原有“下层遮色、露顶自动揭示”的规则。

| 状态或动作 | 当前规则 |
| --- | --- |
| 观察 | 完整显示真实颜色及辅助符号；在将隐藏的份额上画虚线框。不限时，不能移动；点击“准备好了”开始 |
| 黑色块 | 仅隐藏指定份额的颜色、符号和读屏色名；液量、层位与瓶位仍可见。随液体单位身份移动，不按所在格重新遮色 |
| 搭配 | 接触的源顶份与目标顶份中，只要有一份黑色就兼容；两份都显色时须同色。空瓶可接水，仍只从顶部倒出且遵守容量 |
| 移动量 | 黑色每次一份；显色倒最大连续同色顶段，遇黑色停止，且不超过目标余量。隐藏真实色不参与合法性或数量判断 |
| 再看 | 免费完整显示当前排列，暂停移动；主动关闭后恢复同一批单位的黑色状态，不永久揭示，不限次数 |
| 自动揭晓 | 所有非空瓶均装满四份，且每瓶除黑色外至多一种可见颜色（全黑瓶也符合）时自动恢复真实颜色。只检查公开排列，不用隐藏真实色决定触发；真实四份单色才通关，黑色放错仍按答错恢复 |
| 答对 | 完成本题，播放现有完成表现，再显示下一题；百题结束可再玩一轮，无第 101 题 |
| 答错 | 保留真实排列，暂停倒水并检查普通规则下可解性；撤销与重来仍免费可用 |
| 继续整理 | 仅找到并完整回放验证当前真实排列的普通解法后开放；点击后完全显色，按普通规则继续，黑色万能能力结束 |
| 已证无解 | 不开放继续整理，提供原有重来及可用的撤销；不能因为还有合法动作就声称可解 |
| 搜索未知 | 预算不足、取消或尚未完成均不等于无解。继续整理不可用，明确提示暂未确认，可撤销或重来 |
| 撤销 | 回退排列与历史，不回退已揭晓颜色；即使回到揭晓前的排列也完全显色，进入普通整理。隐藏阶段撤销仍保留隐藏单位身份 |
| 重来 | 回原排列和完整观察，建立新尝试，重新应用本题固定遮色方案 |
| 后台／返回／重启 | 恢复自己的观察、整理、查看或揭晓状态，不自动赠送完整查看，也不补播揭晓动画 |

揭晓前不会用隐藏色拒绝接水、自动合并黑色份额、显示隐藏瓶的已完成瓶塞或提前通关。自动揭晓只由公开排列触发，逻辑结果随最后一步提交，倒水回位后播放揭晓。黑色水流、瓶口与接水涟漪采用中性色，不能从动画、符号或读屏获得真实色。已知颜色自身完成仍可正常呈现。

按需一步提示免费，点击后仍自动演示一步，不新增确认操作。参考路线按真实颜色与隐藏状态识别瓶位置换、空瓶交换等价局面，映射回当前瓶号；偏离后采用保留全部黑块搭桥动作的有界加权搜索，寻找任意可靠完成路线，不要求最短。可接回已验证的参考／缓存后缀；成功路线完整回放验证合法移动量、隐藏身份与自动揭晓边界后才执行首步，不能经过提前答错的排列。仅在内存为当前一道题缓存至多 256 个路线状态，重来／撤销仍按实际局面匹配，换题替换缓存，不写玩家库、不改变离线评级。

提示可使用完整真实信息，是辅助而非纯记忆作答；黑块仍保持黑色，说明只依据可见位置与兼容规则，不透露真实色名。成功时源瓶／目标瓶短暂描金，底部显示瓶号方向和简短原因（移开黑块、黑块兼容、空瓶腾位或同色合并），倒水结束后保留约四秒；手动选择／移动、查看、撤销、重来、返回、后台和窗口变化取消。找不到可靠路线明确说明暂未找到，不随机倒一步，不把预算未知当成无解。可解性检查只在自动揭晓答错处和请求提示时运行，不对每次倒水进行完整搜索。答错检查为 100,000 状态／1,500 ms；提示仍为 100,000 状态／700 ms、每片至多约 4 ms。桌面通过不等于手机性能验收。

## 界面与表现

主页沿用独立“颜色记忆”入口与关号。棋盘顶部只显示关号；不增加模式／阶段状态栏或逐题教学。沿用十五款免费玻璃、原有四等份液体、大瓶全宽布局、每排最多六瓶及轻点倒水；保持现有 1900 ms 倒水与水声。移动美术可横向越界裁切，不为动画缩小瓶子。

进入记忆时保留首页，记忆棋盘在隐藏层完成尺寸测量与瓶子布局后一次显示完整页面，不先露出空框，也不增加固定等待时间。准备期间屏蔽输入、教学与水声，开始实际显示后才记录进入及观察／思考时长；返回取消准备，迟到布局回调不能重新打开页面。

首次教学用手指完整演示记忆第一题：观察虚线标记、点准备、变黑、逐步倒水、外观完成后自动揭晓与通关，去掉大段可见说明，保留本地化读屏描述。可直接开始、重播或返回，确认后沿用原有 SQLite 教学偏好只显示一次。示范独立回放已验证路线，不改变玩家尝试、关号、统计或主线钱包；玻璃、声音、辅助符号和减少动态效果遵循当前偏好，后台或窗口变化停止并允许重播。开局大“准备好了”眼睛收成右侧第四个查看／整理按钮；底部四工具依次为撤销、提示、重来、查看，保留至少 44 点点击区域。没有“揭晓答案”按钮，也不显示查看次数；原反馈区在成功提示时短暂解释这一步，其余只在答错、卡住或保存失败时显示必要反馈，答错可用时显示继续整理，不增加弹窗链或判定卡片。查看次数及查看时长仍在本机 SQLite 统计。

观察标记沿实际单份杯腔轮廓绘制，使用深藏蓝 `#10243A`／暖白 `#FFF6DF` 及反色衬边；按底色选择，不改变轮廓大小。标记可以位于顶层，不再为自动顶段显色让位。黑色为不透明中性灰 `#3D4853`，保留独立边界与问号；临时查看不重画初始标记。符号开关、器皿切换和恢复都不能额外揭色。

380 ms 局部渐显与柔光只在自动揭晓后播放，普通倒水不触发。归位后直接使用合并好的真实液体，按瓶合并相邻遮色区域并同步淡出黑色遮罩，不逐份叠加彩色块、扫光或边框，也不在动效结束后重新拼合颜色。最后一次倒水期间预挂载不可见的揭色与完成图形；遮罩由倒水 UI 时钟在归位帧先置为不透明，再更新真实液体并淡出，避免提前显色闪回。完成图形预备时即将其本地动效时钟置零，瓶塞与柔光仍在揭色结束后开始，避免落座瓶塞先闪现再重播；静止瓶不随倒水进度逐帧更新。真实知识与结果先提交并保存，动画不控制状态；撤销、重来、查看、返回、后台、窗口变化或减少动态效果均取消剩余表现。中断／冷启动直接显示已保存结果，不补播。答错检查在揭晓表现结束后启动，减少争用。

## 百题遮色策略

题目由已验证的普通棋盘、固定遮色单位及规则版本组成；手机不随机遮色。沿用原百题的 100 个互异物理底题，95 个可重建生成来源及五个手工布局，重选遮色并重新计算黑色路线，稳定题目 ID 保留。旧观察规则的试验尝试不转换为新规则；新尝试从第一题开始，随后正常恢复自身数据。

| 制作约束 | 当前值与目的 |
| --- | --- |
| 规模 | 2–8 色，每色四份，两只空瓶，总计 4–10 瓶；初始同一瓶同色至多两份，无完成瓶 |
| 隐藏量 | 1–12 份，涉及至多六瓶，沿用十单元的教学／恢复／爬坡／次峰／主峰配方 |
| 层位 | 四层都可选，每题至少一份顶层；四份以上必须覆盖全部四层，避免只遮底层 |
| 分散 | 同一瓶开局至多两份且不相邻；两份以上跨上半／下半层，多份题至少涉及两种真实颜色 |
| 移动价值 | 两条完整黑色解法中，各至少一半隐藏单位实际移动；独立记录每份首次转移、黑色转移及显色倒到黑色的次数 |
| 固定与去重 | 同题每次遮色一致；底题按颜色重命名／瓶位交换进行结构去重，遮色图样另统计，不把换色换瓶当新物理题 |

当前百题共有 777 份隐藏，底到顶分布为 **239／149／146／243**；各层均占 15%–35%，100 题都含顶层，遮色结构有 69 种。并非每道少量遮色题都强行塞满四层；跨题分布和题内分散共同控制。

前 1–3 题为 2–3 色、1–2 份隐藏；4–10 为 3–4 色、2–4 份；11–20 为 4–5 色、3–6 份；21–30 为五色、4–8 份；31–60 为 5–6 色、6–10 份；61–100 为 6–8 色、8–12 份。保留两只空瓶，不用减少空间、强制计时或限制帮助制造难度。

十题单元位置 1–2 恢复／巩固、3–5 爬坡、6 次峰、7 恢复、8–9 组合、10 主峰，首单元前三题教学。主峰隐藏量目标依次为 4、6、8、8、9、10、10、11、12、12；相邻增色最多一色且不同时增加隐藏，单次隐藏增长至多两份。M1／M2／M3／M4 制作标签为 4／13／36／47，表示沿用的内容试排意图；原先按自动揭示延迟解释的难度证据不再适用，不能称为已验证的新规则难度。须观察记忆跟踪、空间整理和识色各自负担后重标／重排。

## 黑块搭桥评级与校准试排

10 月 9 日用户本人已试玩原有百题的前 20 关（不是新选出的二十题校准包），偏好记忆玩法，认为主要难度在记忆，整理排序难度一般；黑色兼容能力减轻了排序压力。最大的体验区别是：记忆游戏需要安静的环境与集中注意力，经典排序更适合碎片时间。这是个人体验依据，尚无外部玩家校准，不能据此推定所有玩家的偏好或全百题难度。原 M1–M4 仍是制作目标标签，新双轴评级另按下述模型计算。

用户已批准按双轴评分与变化配方实现。离线模型为 `memory-bridge-decision-v1`，初始综合公式 `D=round(0.6M+0.4S)`；三个分数都是 0–100 制作代理，仍需真人校准。它不沿用经典最短路或把黑块当作显色块：黑色倒入异色、显色倒入黑色、临时搭桥后拆桥均进入搜索。移动合法性、数量及公开揭晓条件不读取隐藏色；真实颜色用于最终答对目标和选择后果验算。搜索者找到一条正确路线，不代表玩家已经记住路线中的颜色。

M 不假设玩家记住隐藏标签。已知每色共四份，扣除可见份额后，初始隐藏标签排列数为 `N=H!/∏h色!`；同色份额不可区分。再计算同一公开终局能接受的标签排列数 A（全黑满瓶可交换整色），有效信息 `B=log2(N/A)`。只有一份隐藏、或隐藏份额均为同色时，不能靠隐藏数量获得记忆分。其余路线特征按规范化后的实际黑块最短路计算，瓶位／颜色重命名不改变分数。

| M 分项 | 初始权重与定义 |
| --- | --- |
| 有效信息 | 35 分，B 以 22 bit 封顶 |
| 同时追踪 | 25 分，峰值追踪瓶数扣一后以五瓶封顶；满且真实同色、带显色锚点的瓶作为乐观整组扣除 |
| 移动混淆 | 25 分，隐藏份额重复转移、黑顶被覆盖、异色搭桥次数之和，以 `1.5H` 封顶 |
| 保持跨度 | 15 分，隐藏份额最后转移／作为接水黑顶的平均动作位置，以 24 步封顶；不使用动画或等待秒数 |

后三项乘以 `min(1,B/3)`，各项分别四舍五入。M 是指定规范化最短路线的代理，不声称覆盖所有玩家策略或测量了真实记忆能力。

S 重新求解完整黑块规则，在最短路的开局、约三分之一和三分之二处枚举实际合法选择，合并同构后继并去掉立即回到前一步。所有异色搭桥仍保留。每个后继搜索最多允许比最短路多两步：找到完整正确路线即为低代价选择；完整搜完该深度仍未找到，才证明至少多三步，不能称为全局无解；公开满瓶但真实颜色错误是立即答错终点，搜索不能穿过去。任何必需的搜索超出状态／时间预算，S 和 D 均为未知，不能给高分；已完成的 M 可单独保留。

S 的选择负担占 60 分：三个采样点中绕路／立即答错选择的比例，乘 `min(1,log2(选择数+1)/3)`，按峰值 60%／均值 40% 合成。空间压力占 25 分，取最短路中没有整只空瓶的局面比例；操作量占 15 分，步数扣六后以二十四步封顶。此分解是第一轮可调权重，不把搜索耗时、访问状态数或未知分支算入难度。

另作匹配对照：只禁止跨真实颜色接水，仍保留相同遮色、黑色一次一份和揭晓条件，重新求解并记录步数差。这用于核查万能搭桥的实际收益；对照未知只表示该项证据不足，不否定已完成的正式规则评级。允许搭桥却未缩短某一条最短路，也不表示它没有提供新的低代价选择。

二十题配方 `memory-two-axis-calibration-v1` 已实现：前三题教学、六道记忆主导、三道排序变化、四道次峰／主峰、四道恢复；两道记忆题专门选有实际搭桥路线的题。它按 M／S 目标选题，不按 D 单调排序；相邻挑战至少上升四分，挑战超过前段至少三分，恢复至少回落十分。只选完整评级题，必须有有效记忆信息（教学例外），排除开局已经外观完成的布局，沿用原来源／分散遮色／双路线验证并再次检查物理底题不重复。规范化最短路排除了参考路线被人为加长的搬运，但“有趣”仍须实际试玩确认。

实现入口为 `memoryDifficulty.ts`、`memoryRatingSearch.ts`、`scripts/memory-rating.ts` 和 `memory-calibration-lib.ts`。`npm run memory:rate` 验证原百题后输出带题库哈希、规则、模型和预算的 `builds/memory-rating/report.json`，以及 `calibration-20.json`／`.csv`；校准包引用稳定题目 ID 并附完整来源题。默认每次搜索 300,000 状态／2,000 ms，可用 `--states`／`--milliseconds` 离线复核。最短路线再通过共享倒水核心独立回放。此工具不导入手机，不改百题顺序、运行 SQLite、玩家尝试、钱包或 Premium 边界；二十题是校准选题包，尚未接入手机试玩入口。

10 月 9 日以每次 1,000,000 状态／10,000 ms 复核现有百题：97 题完整评级，99 题取得黑块最短路；94／96／99 的部分必需搜索到状态上限，保持未知。24 条规范化最短路线实际使用异色桥；35／69／75／89／95／96 的匹配对照证明允许搭桥少一步，96 的该项证据不补齐其未知总分。二十题已完成确定性选取与底题去重。新增七项回归覆盖百题全部参考路线及合法后继的共享核心比对、两组小棋盘完整图的最短路／下界核验、未知处理、改名换位不变性和配方节奏；此前全量 215 项通过，新增完整图强化后另跑相关回归。它们验证算法与约束，不是手机性能或真人难度证据。

先用代表题校准首次揭晓、辅助与有效思考时长，再决定重排百题和千题生产；同底题重复体验须区分熟悉度。商业范围由[创意与商业规则](gameplay-ideas.md#颜色记忆的付费边界与近期重点)维护，个人表现／选题界面暂缓。

`scripts/memory-bank.ts` 按 `memory-dispersed-wave-v1` 确定性选择遮色；`memory-bank-lib.ts` 独立重建来源、普通最短参考路线、两条黑色路线及单位证据。普通路线在遇黑色处拆分为一份操作，再由独立回放器和运行核心分别验算；不会将普通连倒路线直接当新玩法解法。自动揭晓前隐藏数恒定，证据记录移动而非旧首次显色曲线。现有百题的两条路线均仅在最后一步满足公开揭晓条件；辅助搜索不穿过已触发但答错的黑色局面。任一来源、约束、目标、路线、证据或结构去重不符即拒绝导出，不以搜索超限充当可解或无解证明。

JSON 是离线输入，运行只读 `content.sqlite`；导出后逐项读回百题、遮色、双路线及证据，同时检查原 1000 主线／50 副关、完整性、外键与哈希。诊断输出在忽略的 `builds/memory-100-report.json` 和 `builds/black-memory/`，不作为文档归档。

`src/game/memory.ts` 管理稳定单位身份、知识、判断结果和 4096 步有界撤销；`memorySolver.ts` 提供分片辅助。揭晓边界区分历史黑色规则与后续普通规则，撤销后仍保留已知颜色。恢复会校验份额唯一性、颜色守恒、历史每步合法性和计数，不依赖动画。

同一玩家 SQLite 中新规则使用 `memory_black_session`、`memory_black_layers`、`memory_black_knowledge`、`memory_black_attempts`，教学偏好为 `memory-black-v1-tutorial`，不读取或迁移旧观察玩法试验记录。初始化只创建新规则数据，不清空主线、钱包、设置、安装 ID 或既有统计；后续启动必须恢复新规则自己的尝试。与主线共用串行事务、失败重试和修订去重，无 JSON／AsyncStorage 双写或兼容层。

记录观察、查看、解题、阻塞时长及实际倒水／提示／撤销／重来／揭晓和检查结果；查看时暂停操作，后台不计，口径遵循[统计方案](gameplay-statistics-plan.md)。揭晓即正确记录 `remembered`，揭晓后普通整理完成为 `recovered`，撤销再完成不覆盖已发生的首次成功类别。不发主线积分，不改钱包或待解主线。

## 当前验收与待校准

此前黑色规则的 189 项自动回归、TypeScript、ESLint、网页导出与百题独立验证通过；10 月 9 日自动揭晓及界面精简增量的验证范围见[当前基线](current-baseline.md)。覆盖四层分散、黑色兼容／单份移动、隐藏身份持续传播、自动揭晓条件、完整解法方可继续、未知与无解区分、揭晓后撤销不回黑、SQLite 重启恢复、失败事务重试、统计类别和第 100 题循环。浏览器、iPhone 及 Android T517D 的实际记录统一维护在[设备支持](device-support.md)，未实施的平台不套用其他平台结果。

前 20 关的个人体验支持继续以记忆为主要挑战、用排序提供变化，不以增加整理难度作为默认改进；当前 60%／40% 初始权重不因单人反馈直接调整。后续真人校准需注明安静／易受打断的体验环境与实际中断，区分题目负担和注意力被打断的影响；不由此新增强制计时、失败惩罚或环境限制，也不声称提升记忆力或已证明大众趣味性。重点体验黑块搭桥、移动跟踪、免费查看、答错恢复和恢复题是否舒适；用规模相近的全显色及少遮色对照，避免同底题熟悉度污染。十五容器、读屏／符号、小屏、水声、持续性能和 TV 遥控仍按设备单独验收。调色、彩虹配方、作品呈现、商业资源与严格限时没有因本次反馈自动启用。
