# 千关制作配方

当前内容 `mainline-1000-v5`，配方 `thousand-mountain-v1`，评分 `human-decision-v1`。玩家流程见[游玩流程](play-flow.md)，评分定义见[难度校准](difficulty-calibration.md)。

## 内容约束

- 固定 1000 道顺序主线，四层容量，2–11 色、4–12 瓶、1–2 个空瓶；前三题为两三色教学，其余至少四色；参考解法最多 60 次倒水。
- 每只初始瓶内同色总数最多两层，包括不相邻层；没有初始完成瓶。D3／D4 装水瓶至少三色。限制只作用于来源与导入，游玩中正常合并不受限。
- 来源为 526 道 `balanced-shuffle-v1`、474 道 `anchored-shuffle-v1`；`layered-shuffle-v1` 只保留旧来源重建。所有题精确结构互异，没有所有装水瓶底两层都同色的开局。
- 完整目录保留来源、参考解法、旧规划证据、人类代理证据、`classic-features-v1` 标签及波次角色；运行投影严格对应，手机不做完整评级。
- 293 道双空瓶题逐一移除末尾空瓶：9 可解、284 确证无解、0 未知。排除教学后，7 道可选备用瓶为 4、65、68、193、364、463、485。名单须对最终目录独立重算；单空瓶变体不沿用完整题分数。

## 山峰编排

50 个二十关周期，每十关依次为两关缓冲、五关爬坡、两关蓄势、一关挑战；首轮前三题教学单独处理。第十关为次峰，第二十关为主峰；另按五十关汇总 20 个报告阶段。

| 项目 | 导入与制作共同检查的约束 |
| --- | --- |
| 高峰走势 | 次峰、主峰两条序列分别不下降；主峰至少高于本轮次峰 4 分 |
| 挑战突出 | 每个挑战至少高于前九关最高分 5 分 |
| 峰后恢复 | 挑战后的两题各比挑战低至少 12 分 |
| 爬坡 | 同段允许最多 2 分回落；不要求全局普通分或阶段均值单调 |
| 角色目标 | 次峰从 40 升至 69，主峰从 45 升至 74；缓冲从 18 升至 41，第二段缓冲加 2 分 |
| 目标容差 | 挑战在目标至目标 +3 内；其他非教学题与角色目标最多相差 8 分 |
| 首轮接入 | 非教学练习目标依次为 14、20、24、28、32、35 |
| 高峰质量 | 规划级至少 4；目标低于 55 时风险峰值贡献至少 5，否则至少 8 |
| 缓冲质量 | 风险峰值贡献至多 12、风险反复贡献至多 3；参考路线无两步连续准备；双空瓶缓冲移除空瓶后须证明无解 |

缓冲和全部高峰按完整评级瓶数开局。颜色／规模偏好是软建议：缓冲偏好四至七色，其他非教学题四至十一色。选题先保障稀缺高峰和缓冲，再匹配爬坡供给与优化相邻变化；不宣称全局最优。

当前角色数为教学 3、缓冲 198、爬坡 499、蓄势 200、次峰 50、主峰 50。D1／D2／D3／D4 为 **8／315／510／167**，是观测结果而非配额。全库平均分 42.051，挑战平均 57.04，第 10／20／1000 关为 40／45／76；峰后回落最小 17、平均 26.21。这些代理数值仍需真人校准。

## 凝固副关

每完成二十道主线插入一题，共 50 题，不替换主线编号；完成主线 1000 和副关 50 后结束。目录 `assets/levels/solid-side-50.json` 包含三／四／五／六色各 10／12／14／14 题。每题颜色数 +1 只瓶、四格分散空位，无整只空瓶，目标瓶底层凝固；可免费融化。

所有题在凝固与融化状态分别求最短解、完整回放，结构去重保留目标瓶身份。排序使用独立首步风险与操作量，不套用主线分数。实际节奏为主峰 → 副关 → 缓冲，连续试玩须检查两种副关状态是否延长压力。

## 验收与更新

`productionPlan.ts` 定义目标与约束，`waveSelection.ts` 选题，`scripts/replan-mainline.ts` 产出目录和绑定哈希的报告。正式接入前逐题来源重建、完整求解回放、完整低策略检查、人类代理与标签独立重算、全局精确去重、角色与峰谷校验，以及最终备用瓶审计全部通过；预算未知不得填补证据。命令见[生成与验证](generation.md)。

现行千关已完成上述独立复核，运行投影一致；50 副关双状态验证通过。更改规则、公式或配方需更新相应方法版本并重新验证。当前源码采用[SQLite 新基线](gameplay-statistics-plan.md)，不兼容旧开发存档；保留当前题目与全部验证证据。真正开始玩家测试后的内容变更须保护新基线进度，不为未上线实验维护历史题库。
