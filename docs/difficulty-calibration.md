# 难度模型与校准

现行千关按 `human-decision-v1` 分档；它是人类难度的结构代理，尚未经玩家验证。八道 C 样本及原始演示仅作内部对照，其试排 D1–D4 不等于主线分档。

## 当前人类决策代理

独立求最短路线并规范瓶位与颜色，在起点、约三分之一和三分之二处枚举不同合法后继；排除立即撤销和不必要地打乱完成瓶。逐一求精确后续最短距离，`regret = 1 + 后继最短距离 - 当前最短距离`：至多 2 步为可恢复，至少 3 步为高成本绕路，完整穷尽无解为死路。错误选择若减少颜色段数，增加诱惑风险权重。任一所需分支预算不足，整题评分为 unknown。

| 分项 | 分数上限 |
| --- | ---: |
| 已完整验证的规划级 1–8 | 10 |
| 三个观察点的选择风险峰值及均值 | 35 |
| 风险达到 0.25 的观察点比例 | 10 |
| 单空瓶及路线中无空瓶状态的空间压力 | 15 |
| 2–11 色的视觉规模 | 15 |
| 最短倒水操作量，约 30 步达到上限 | 15 |

精确公式以 `src/game/humanDifficulty.ts` 为准。D1 `<20`、D2 `20–34`、D3 `35–54`、D4 `55–100`；不固定数量配额，不使用机器耗时、搜索状态数、动画时间或玩家历史评分。调整公式或权重须升级方法版本并独立重评，编排约束见[制作配方](production-plan.md)。

## 保留的规划证据契约

`planning-depth-v1`／`planning-load-v1` 的八级证据仍保存在完整主线目录，旧总分不再用于排序。内部 C 报告采用 `planning-frontier-v1` 四层策略；两种等级不可互换。

颜色段数 R 为各瓶连续同色段之和；整理段由合法倒水组成，到首次 R 减少时结束。此前 R 不变为准备动作。只搬单色整瓶造成的瓶位变化不算新选择；实际路径仍逐步回放。局部合并不保证安全。

| C 对照策略 | 整理段倒水上限 | 候选之后的前瞻 |
| --- | ---: | --- |
| P1 | 2 | 不检查后续整理段 |
| P2 | 4 | 1 个整理段 |
| P3 | 6 | 依次检查 2、3 个整理段，保留最低通过深度 |
| P4 | 完整合法路线 | P1–P3 均已完整未通过后，以完整规则验证 |

枚举全部非等价候选段，合并相同后状态，保留最短合法代表路线。P2／P3 仅排除在前瞻边界前所有路线均卡住的选择；随后保留最短整理段的全部并列前沿。验证器须展开所有策略前沿，不能用完整解法替低策略挑选幸运路径。通过保存路线，未通过保存卡点反例；某策略卡点与无合法移动、完整规则无解分别记录。

八级主线策略的具体配置由 `difficulty.ts`／`difficultyLoad.ts` 定义。最低策略判定要求所有更低策略完整检查；低层超限只能报未知，已找到高层解法最多是上界。策略证据必须与共享规则回放一致，调换同类瓶位或颜色改名不改变评级。

## 人工校准与工具

`assets/levels/calibration.json` 为 C01–C08，`calibration-difficulty.json` 保存对照报告，题号与试排分组在 `calibration.ts`。内部入口不保存进度、发券或覆盖正式主线。D3／D4 对照开局每瓶至少三色、同色至多两层，D1／D2 保留 relaxed 筛选。

C06 与 C07 都是 14 步，用户认为 C07 最难；这是具体人评锚点，支持区分操作量与选择压力，不能推导全库已定级。初始空间比 E/C 及路线无空瓶比例用于解释空间压力，不单独决定难度。

盲测覆盖前 40 关、中后段完整周期及副关，记录独立完成、关键选择、撤销／重来／提示、主观难度和恢复感。倒水约 1.9 秒，通关总时长不能直接作思考时间；本地挑战／尝试、操作与单调时间统计已实现，见[统计专题](gameplay-statistics-plan.md)；外部玩家校准尚未进行。视觉难辨与规则难度分别评估。

```sh
npm run levels:rate -- --include-demo --require-rated --verify assets/levels/calibration-difficulty.json
npm run mainline:verify
```

校准回归须覆盖低层完整性、正反例回放、预算未知、穷尽无解、颜色／瓶位对称、确定重评、报告绑定及同一装水排列增加空瓶的对照。真人结果与代理不符时修正模型，不为保持旧分组调整结果。
