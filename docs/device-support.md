# 设备支持与验收

截至 2026 年 10 月 8 日，适配已覆盖 iOS／Android 手机和平板、PC 浏览器、Android TV 与 Apple TV；发布状态见[发布记录](release-readiness.md)。最低构建声明为 iOS／tvOS 16.4、Android API 24，target API 36，最低系统性能尚未验收。

## 当前布局与输入

4–12 瓶两排、每排至多六瓶，同窗口统一大瓶、十五款等比缩放、手机全宽；移动瓶允许横向越界裁切。手机竖屏；iPad 支持旋转与窗口变化，Android 最小宽度达到 600 dp 时解除竖屏限制。宽度至少 600 且大于高度 1.15 倍使用侧栏；TV 固定侧栏、四周至少 5% 安全区、字号 1.4 倍。

浏览器支持鼠标、触控、Tab、方向键、Enter／空格；Escape 先取消源瓶再回首页，弹层打开时停用棋盘键盘。TV 原生方向焦点有独立金色框、开始／首瓶／继续首选焦点，Apple TV Menu 在游戏和弹层返回、首页遵循系统离开。动画期间同步 busy gate 拒绝重复动作。列表与文字页面可滚动。

浏览器最小布局宽 320，竖向至少按高 520、侧栏至少高 400 布局，矮窗可滚动。旋转／调整窗口／后台取消表现并显示已提交状态；浏览器动画后恢复焦点。18／24 瓶方向见[后续区域方案](gameplay-ideas.md#四个游戏区域题库规模与提示资源讨论方向)，当前未接入。

## 构建方式

React Native 使用与 Expo SDK 57 同核心版本的 `react-native-tvos@0.86.3-0`，同时支持移动端与 TV。`.npmrc` 使用 `legacy-peer-deps=true`，解决稳定 TV 分支带预发布后缀时既有原生依赖的 peer semver 拒绝；版本和锁文件一并固定。Expo 的 TV 配置插件只在 TV 构建启用。

```sh
npm ci
npm run web
npm run web:export
npm run ios
npm run android
npm run prebuild:tv
npm run ios:tv
npm run android:tv
```

浏览器导出位于 `dist/`，需通过静态 HTTP(S) 服务提供。没有部署到公网。浏览器存档属于当前浏览器和来源站点；更换域名、浏览器或清理站点数据不会同步到其他设备。当前没有云同步。

TV 命令将当前源码、素材和配置复制到忽略的 `builds/tv/`，链接同一套依赖，在该目录生成 TV 原生工程。它是构建快照，不是 Git 分支或 worktree，不清除根目录的手机原生工程。TV 的商店图标、展示素材、签名及发布流程仍须按目标平台完成；现有 Android 政策文本不能直接作为所有新平台的发布验收。

移动端与 TV Android 工程共享依赖中的 Gradle 原生输出，必须依次构建，避免并发构建争用这些输出。本次原生检查使用 `builds/device-compatibility/tv/` 等价快照，脚本默认生成目录为 `builds/tv/`。

Chromium 内部构建检查 320×400 至 1920×1080 的 11 种窗口、十五容器、德语长文与阿拉伯 RTL、刷新恢复、提示与弹层。`audit:layout` 对 9 种瓶数 ×15 款 ×11 窗口共 1485 组静止轮廓／点击区检查通过，最小可见间隙约 4.72；不含描边、光晕或移动美术。

独立 Android 模拟器还检查了主线／副关／重玩恢复、十五款偏好、卡住提醒不连环、无解／未知区分、音频起始水位、静音和后台取消。iPhone 已安装涟漪可见度修正版；模拟器音频检查不是手机延迟或听感测量。辅助符号 `ab80e1f` 仅有本地网页与几何回归，尚未重新打包手机。

原生／布局证据在忽略的 `builds/device-compatibility/`；14 张平台截图、哈希与场景重拍文件在 `builds/release-0.1.1/`。新截图按用户要求只留本地，未加入 Git 或上传商店；现行商店仍使用已批准手机截图。场景注入只用于展示，不作自然通关证据。

## 安装与待验任务

Android 使用[发布记录](release-readiness.md)指定 AAB／APK，先核对版本、签名和哈希；本轮整理不执行卸载或清数据；SQLite 新基线按已确认方案不继承旧开发数据，未来玩家数据须保护。iPhone `npm run ios:device` 为不依赖 Metro 的开发签名 Release；模拟器包不能装真机。

实际开始测试时核对采用的包与存储基线，检查该基线内的恢复、提示券与偏好；持续体验前 40 关、高峰 → 副关 → 缓冲、重玩隔离、提示与奖励不重复、卡住恢复、后台／窗口变化、符号与设置。真实设备还需检查最大字号、小屏、十三语种及最低系统、TV 观看距离和遥控操作。

扬声器与耳机检查十五款声音同步、空／中／近满接水、重复疲劳、静音与迟到取消；低端 Android／iPhone Release 连玩 10–15 分钟测帧率、温度、耗电、搜索最长切片、内存和保存。先测 TypeScript／Hermes，再决定 C++。Safari／Firefox、Windows Google Play Games、平板和 TV 真机持续体验尚未完成；反馈方式见[测试安排](play-testing-plan.md)。
