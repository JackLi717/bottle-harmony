# 当前十二瓶的跨设备支持

2026 年 10 月 8 日。确认目标为 iOS／Android 手机和平板、PC 浏览器、Android TV 与 Apple TV。十八／二十四瓶的自动排布延期，扩展规则见 [布局约定](adaptive-layout-design.md)。本文分别记录已实现的适配、构建证据与设备验收，不能将浏览器窗口样本当成对应原生设备实测。

“覆盖所有设备”以这些设备类型为目标，不等于所有历史系统和机型均兼容。当前生成包的最低系统为 iOS 16.4、tvOS 16.4、Android API 24（Android 7.0），Android target API 为 36；它们是构建声明，不是这些最低系统上的实际性能结论。PC 此轮实际检查 Chromium，Safari／Firefox 仍待补验。

## 当前适配

- 保留 4–12 瓶、两排、每排最多六瓶，同一窗口内所有关卡使用相同瓶子尺寸；十五种容器始终等比缩放。关卡、颜色上限、容量、求解和存档规则没有扩展。
- 手机保留原来的竖屏界面。iPad 支持竖横屏和可变窗口；Android 在最小宽度达到 600 dp 的平板上解除竖屏限制。安全区域使用实际系统边距。
- 宽度至少 600 且超过高度 1.15 倍的窗口使用右侧操作栏，给两排瓶子更多高度。其余窗口保留底栏。TV 固定使用侧栏，并在四周预留至少 5% 安全区域。
- 浏览器支持鼠标、触控和键盘。Tab 进入／退出控件，方向键在瓶子间移动，Enter／空格确认；Escape 先取消源瓶，再返回首页。弹层打开时棋盘键盘处理停用，输入框不截获方向键。
- TV 使用原生方向键焦点和确认键；主页开始、棋盘首瓶和通关继续提供首选焦点。金色焦点框独立于源瓶的抬起与底部标记。动画期间可保留 TV 瓶子焦点，已有同步 busy gate 继续拒绝重复动作。
- TV 字体放大至常规的 1.4 倍，基础按钮增大；纯文字页面提供可被遥控器滚动的区域。首页和完成效果弹层可滚动。
- 关卡菜单顶部控制区限制高度并可滚动，避免小屏展开内部试玩时挤掉关卡列表；软键盘打开时，跳转按钮一次点击即生效。
- TV 关卡列表按实际剩余高度设定列表高度，适配原生焦点容器；Apple TV 在游戏或弹层中启用 Menu 返回处理，首页保留系统离开应用行为。
- 浏览器窗口低于正常可用高度时允许滚动：竖向界面至少按 520 高、侧栏至少按 400 高布局；最小布局宽度为 320。极矮窗口不要求全部控件同时出现，但必须能滚动到达，不能靠重叠点击区容纳。
- 调整窗口、旋转和后台切换继续结束当前视觉动作，显示已提交的逻辑结果。浏览器动画结束后恢复瓶子键盘焦点。原生 Alert 不可用的浏览器也能显示并关闭提示反馈。

## 构建方式

React Native 使用与 Expo SDK 57 同核心版本的 `react-native-tvos@0.86.3-0`，同时支持移动端与 TV。`.npmrc` 使用 `legacy-peer-deps=true`，解决稳定 TV 分支带预发布后缀时既有原生依赖的 peer semver 拒绝；版本和锁文件一并固定。Expo 的 TV 配置插件只在 TV 构建启用。

```sh
npm ci
npm run web
npm run web:export
npm run ios
npm run android
npm run prebuild:tv
npm run ios:tv
npm run android:tv
```

浏览器导出位于 `dist/`，需通过静态 HTTP(S) 服务提供。没有部署到公网。浏览器存档属于当前浏览器和来源站点；更换域名、浏览器或清理站点数据不会同步到其他设备。当前没有云同步。

TV 命令将当前源码、素材和配置复制到忽略的 `builds/tv/`，链接同一套依赖，在该目录生成 TV 原生工程。它是构建快照，不是 Git 分支或 worktree，不清除根目录的手机原生工程。TV 的商店图标、展示素材、签名及发布流程仍须按目标平台完成；现有 Android 政策文本不能直接作为所有新平台的发布验收。

移动端与 TV Android 工程共享依赖中的 Gradle 原生输出，必须依次构建，避免并发构建争用这些输出。本次原生检查使用 `builds/device-compatibility/tv/` 等价快照，脚本默认生成目录为 `builds/tv/`。

十五种容器已逐一切换；德语长文本与阿拉伯语 RTL 在 320 宽窗口检查。键盘倒水、动画中从窄窗改为横屏、焦点恢复、提示及提示券用尽反馈、弹层 Tab／Escape、刷新后的局面和容器偏好恢复均已操作确认。

正式导出的浏览器构建另外完成首关五步通关、完成展示结束后出现继续按钮、提示券奖励与进入第二关；没有内部预览箭头。浏览器观察未出现运行错误；开发构建有既有 shadow／pointerEvents 弃用提示。尚未验证其他浏览器引擎、浏览器声音的听感或长时间性能。

`npm run audit:layout` 使用上述实测舞台，检查九种瓶数 × 十五种容器 × 十一种窗口，共 1,485 组静止填充轮廓与点击区域；均未相贴或越出静止棋盘，最小可见空隙约 4.72。该测量不包括轮廓描边、光晕、焦点和移动中美术，也没有使用未来扩展的最小间距参数。

本机检查产物位于忽略目录 `builds/device-compatibility/`：窗口测量 JSON、容器几何 JSON、实际画面及构建日志。自动测试 150 项通过；TypeScript、ESLint 与 Expo Doctor 21 项检查通过。更改不涉及生成或发布新关卡。

## 原生设备验证状态

以下均为本机模拟器或构建检查，不是真机验证。

本轮原生安装包以 ARM64 为验收目标；其他 Android ABI、商店分包和正式签名还没有完成发布验证。

- iOS 移动端 Release 编译成功，使用统一 TV 运行时的新包在 iPhone SE 第三代／iOS 17.5 与 iPad Pro 11 英寸 M5／iOS 26.5 安装运行。iPhone 完成首页、引导、选瓶倒水、撤销和第 673 关十二瓶显示；菜单最终修复也验证了软键盘打开时一次点击跳转。
- iPad 新包完成首页横屏、首关倒水中旋转、逻辑结果保留、撤销，以及第 673 关十二瓶横屏侧栏／竖屏底栏。旋转后源瓶三层、目标一层，撤销恢复四层和空瓶。
- Android 移动端 Release 安装包编译成功，生成的 MainActivity 包含 600 dp 平板旋转规则。此轮尚未操作 Android 手机或平板原生界面，不能将浏览器样本替代这部分验收。
- Android TV Release 安装包编译成功；清单含 Leanback 启动入口、必需 Leanback 和非必需触屏。已在专用 API 34 ARM64 TV 模拟器（1920×1080，density 320）安装成功。当前电脑控制工具无法绑定其外部模拟器窗口，现有 Android Studio 也未显示可控制的嵌入窗口，因此遥控器交互仍待验证。
- Apple TV Release 模拟器包编译成功，在专用 Apple TV 4K 第三代 1080p／tvOS 26.5 模拟器安装运行。已用方向键和确认键完成首页进入、引导关闭、首瓶选择、向第三瓶倒水、进入侧栏和撤销；倒水后三层／一层，撤销后四层／空瓶。最终包另验证了关卡列表、顶部滚动区、关号输入和第 673 关十二瓶完整显示，以及 Menu 从棋盘返回首页和关闭菜单。

完整发布验收仍需真实 iPhone／Android 手机、iPad／Android 平板、Android TV／Apple TV 的持续游玩，以及 TV 实际观看距离下的文字、色层、焦点和遥控器操作检查。最大系统字号、最低系统、不同浏览器引擎和低端设备性能尚未完整验收；商店兼容范围应以各平台最终构建和设备验证为准。
