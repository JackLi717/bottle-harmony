# 发布前下一步

更新日期：2026 年 10 月 7 日。当前是单人纯玩内测基线，不是已提交商店的版本。

## 当前已具备

- 普通四层瓶统一规则、合法操作回放、撤销/重来、可解验证。
- 离线生成、结构去重、策略评级、80 题四档内容池和制作重验。
- 首次规则说明、连续续题、固定档位与推荐松紧节奏、免费跳过。
- 一局本地保存、冷启动合法回放恢复和跨退出撤销历史。
- 原创瓶子美术、多瓶布局和已有手机试玩反馈；新版设备结果见设备记录。

## 先完成设备与内容复测

连续玩各档题，记录实际所需思考、卡点与重复感，特别比较 D3/D4；机器评级不代替人测。验证小屏、平板、低端 Android 的多瓶点击、过关续题、跳过、模式选择、切后台与冷启动恢复。补手机上提示求解、保存和启动的时间/内存测量，再决定是否需要 C++；尚未接手机即时生成，不先为它增加后端。

低端安卓真机未连接时不能判定复测完成。新增 80 题须进一步人工抽查体验；独立求解已证明可完成，但不是乐趣证明。题库仍有限，商店描述应写离线关卡与可重玩，不能写无限生成。

## 再整理发布包与配置

当前应用版本 0.0.1，标识 com.bottleharmony.app；发布主体、名称、标识归属、正式签名/分发账号尚未确认。当前图标和 Android 适配图标仍为模板，须制作原创应用图标及启动资源。测试签名 APK 和个人签名 iPhone 包用于内测；不能当作已上传的商店包。

Android 生成主 Manifest 当前含 INTERNET、READ_EXTERNAL_STORAGE（最高 API32）、WRITE_EXTERNAL_STORAGE（最高 API32）、SYSTEM_ALERT_WINDOW 和 VIBRATE。iOS 包含开发时的本地网络说明。纯玩逻辑与 AsyncStorage 的私有进度不需要外部存储或悬浮窗；正式发布配置应通过 app.json/config plugin 阻止不用的权限，并分别核对最终合并 Manifest/Info.plist。开发客户端与正式包的配置边界需要验证，不能只手改生成目录。

安卓原有静态检查发现 GNU_RELRO 16 KB 对齐问题，真实 16 KB 页面环境尚未验证；正式分发前继续处理依赖和页面兼容性。新包的签名、最低系统、目标系统与 ABI 也须按最终产物核查。生成 ios/android 目录、签名材料和安装包保留本地，不入 Git。

依赖核查中 `npm audit --omit=dev` 报告 25 项（18 high、7 moderate），底层来源为 braces、node-forge、uuid，并传导到 SDK/工具链包。须核对正式移动包与开发工具的实际使用路径，并选择 Expo 兼容的修复方案；当前没有用强制跨版本降级来换取审计数字归零，不能据此宣布发布审查完成。

## 最后准备商店材料

确定发布主体后，再准备原创图标、真实设备截图、准确的中英文介绍、支持方式、隐私说明与商店数据申报。应用代码当前没有账号、云存档或自行实现的数据上传；完整发布包中的 SDK、权限与网络行为仍须审查后才能填写最终隐私声明。

当前不加入生命、倒计时、付费、广告、好友、机关或每日题。商店发布与用户测试版是分开的最终动作，完成可审核材料和账号配置后再实际提交。
