# 千关主线与本地进度

更新日期：2026 年 10 月 7 日。

当前应用已接入一千道固定编号的实际题目，按[制作配方](production-plan.md)每十关起伏。首三关是两至三色教学，之后普通题优先采用重叠的多色范围；收尾按实际规划难度递增，不按颜色数判难。四档配额为轻松 300、标准 300、思考 305、挑战 95。

## 主线与重玩

从第一关开始，完成后“下一关”解锁下一题。未解锁关卡不可选择，主线没有跳过；撤销、重来、演示一步免费。菜单显示已通过数量，提供当前主线和已过关重玩。选关用五列虚拟列表，不一次挂载一千个按钮，打开时定位当前关卡。第一千关完成后显示主线完成，可选择已通关题，不生成第一千零一关。

完成记录不会因撤销或重来抹除；但当前主线仍保留实际动作历史。重玩有独立局面、动作和撤销历史，进入重玩不会替换尚未完成的主线。“回到主线”或菜单“继续主线”恢复原来的待完成局面。

## 内容与评级

assets/levels/mainline-catalog.json 保存 1000 个固定编号、实际布局、生成来源、完整参考解法、结构键、八级策略证据和固定负担分。制作以实际评级收题，不修改档位凑数，全部来源重建、逐步回放、全球结构去重和独立重算通过后接入。

assets/levels/mainline-play.json 是完整已验收内容的精简投影，保存编号、实际布局、参考路线、内部级、用户档和分数。应用启动只验证此投影的规则、路线、编号、结构唯一与配方；完整策略证据在内部调试打开时延迟加载，手机不运行完整评级。制作验证要求逐条与完整记录一致。

提示优先匹配参考路线上的实际局面，偏离后使用有状态和时间预算的增量求解。搜索达到预算只提示本次未及时找到，不宣布高难或无解。五色以内默认 BFS，更大局面使用 A*；已找到的路线必须完整回放。

## 当前本地保存

AsyncStorage 键为 bottle-harmony.mainline.v1。保存当前关号、连续已完成位置、主线与重玩两个起始题 ID 和合法动作序列、教学状态及辅助符号偏好。不保存动画、选中瓶或搜索状态。动作先提交逻辑状态，再异步按序写入；切后台结束视觉动画、保留已接受的逻辑动作，并重试最近的保存。

读盘结束前锁住游玩入口。恢复逐步回放并恢复撤销历史，严格检查当前内容 ID、编号、解锁顺序、主线/重玩绑定和动作合法性。两个局面各最多 4096 个动作，保存最多 256 KiB。超长或写入失败在菜单说明，保持内存游玩并重试。强制结束进程仍可能早于最后一次异步落盘。

当前预发布只有这一套主线基线；此前自由试玩存档不迁移为通关记录，初次升级会提示从第一关开始。读取失败或损坏不会在挂载时立即覆写已有存储，新的明确操作才建立新记录。数据本机保存，无账号、云同步和上传。

## 视觉与内部工具

四至十二瓶使用两排，每排最多六瓶。较大棋盘扩展可用横向空间并增加独立触摸区域，小屏六列保持至少 44 点且不重叠。十一色各有独立名称和配色，可在菜单切换辅助符号；符号与颜色关联，不固定于瓶子，不改变规则。

用户的内部构建保留调试难度、C 对照题、原始体验，以及十一色十二瓶、十色十二瓶和第 1000 关的内部预览。这些预览不解锁、不记通关、不覆盖主线，也不保存为主线。关闭后通过菜单继续主线。

app.json 的 extra.internalTools 控制内部入口。当前安装版为 true，正式界面可置 false 隐藏内部工具。没有新增每日题、计时、体力、广告、付款或额外瓶道具。

## 生产与验收命令

```sh
npm run mainline:build -- --max-candidates 1000000
npm run mainline:verify -- --input builds/mainline-catalog.json
npm test
npm run typecheck
npm run lint
```

制作断点位于本机 builds/mainline-checkpoint.json，保存固定候选地址、接纳的实际记录、预算、提案方式变化边界和拒绝统计。时间超限停在当前候选，工作/状态预算不足拒收且不贴高档标签；已有成品输出在失败时保留。全部配额齐才写成品，独立重验完成才导出精简包。

目前 1000 题来源/回放/评级重算已全部通过。自动检查覆盖顺序解锁、最终结束、已完成记录、主线/重玩独立恢复、错误存档拒绝、十二瓶全部倒水几何、小屏触摸区域、辅助符号偏好及完整/精简内容对应。安装和手机检查记录见[设备说明](device-testing.md)；持续试玩、帧率、发热、耗电与各设备定量预算另需实测。
