# 连续游玩与本地进度

更新日期：2026 年 10 月 7 日。用户批准按内容池 → 完整游玩 → 本地保存 → 设备与发布验证 → 商店材料的顺序完成纯玩版本。本轮落实前三项，发布验证另行记录。

## 当前玩法

首次用两色四瓶体验介绍点击来源、目标同色或空瓶、连续段与部分接收。规则说明只展示一次，可直接进入自由游玩。没有倒计时、体力、金币或付费道具。

完成后主按钮变为“下一题”。撤销、重来和演示一步仍免费；没有可倒的瓶子时保留局面，可以撤销或重来。右上角“游玩菜单”支持推荐节奏、固定四档、免费换题，以及保留 C01–C08 和原始体验的对照入口。切换模式或选题会开始新题，替换当前保存的一局。

| 模式 | 出题规则 |
|---|---|
| 固定 D1–D4 | 始终取当前实际评级档，不因步数、失败或完成次数强制升级 |
| 推荐节奏 | 按 D1、D2、D1、D2、D3、D1、D2、D3、D2、D4、D1、D2 循环 |
| 对照样题 | 手动挑选八道人工试排题，自动难度另列 |

推荐表是按完成题数推进的游玩序列，不是每周日历。首次有轻松热身，D4 后回到 D1；跳过保持节奏位置、不记完成。只在完成内容池题后点击下一题推进节奏；原始体验与对照题不推进。切换到不同模式重置节奏位置；重复选当前模式保持位置。

首批有限题库共 80 题，每档 20 题。同档候选先排除本轮已经发出的题，稳定选择剩余题；跳过也算本轮已经发出。该档用尽后清除该档的本轮记录，明确提示开始重玩。已完成记录独立保留，完成后撤销/重来不抹去首次完成记录。目前不会在手机即时生成无限新题，不把这 80 题宣传成无限独立关卡。

## 内容生产

`assets/levels/starter-catalog.json` 保存实际布局、生成来源、完整参考解法、结构去重键和离线难度报告。`catalogBuilder.ts` 批量生成候选、求解回放、按实际评级收题、全池结构去重。D3/D4 接纳题必须采用 diverse 开局：每个初始装水瓶至少三色，每色总共最多两层。实际档位与请求档位不同时按实际档收题；档满或筛选不符时拒绝，不修改评级凑数。

当前种子 20261007，218 次生成请求得到四档各 20 题；135 次因实际档已满拒绝，3 次因高档开局筛选拒绝。只有全部配额达成才写入文件；超时或配额不足保留原输出。时间预算是每次生成/评级请求的活跃预算，不是整个批次总时长。单档最多 25 题，整个基线最多 100 题，沿用当前内容池边界。

```sh
npm run catalog:build -- --seed 20261007 --per-tier 20 --output builds/catalog.json
npm run catalog:verify -- --input builds/catalog.json
# 更新正式内测基线时指定实际资源路径，随后审阅差异
npm run catalog:build -- --seed 20261007 --per-tier 20 --output assets/levels/starter-catalog.json
npm run catalog:verify
```

制作重验重新构造来源、完整回放解法并重新计算每道题的难度，要求报告一致。应用载入时验证布局、来源、路线、绑定和结构去重，不在启动时重新求解/评级。提示优先复用参考路线中匹配的实际棋盘，偏离后才用有预算的增量求解器。

内容池的 D1–D4 是首版策略模型的自动暂定评级；不是经大量人测校准的分数。数组内按档位、参考解法长度整理，仅用于稳定制作顺序，解法长度不替代策略难度。F001–F080 是当前基线显示标签，实际 ID 才是保存引用。八道 C 对照题仍独立保留，编辑试排与自动评级不混用。

## 本地保存

AsyncStorage 2.2.0 采用 Expo 兼容版本。键为 `bottle-harmony.play.v1`，当前只有一个存档槽，保存在应用的本机私有数据目录。数据不上传服务器；卸载或清除应用数据会删除它，系统备份行为另由平台决定。本轮没有账号、云同步或跨设备恢复。

保存内容为：实际初始关卡定义、合法动作来源/目标序列、当前模式、推荐节奏位置、稳定选题计数、本轮发题 ID、首次完成 ID、教学已读状态，以及是否进入重玩。本次保存不单独信任当前棋盘；从初始布局回放动作恢复棋盘、完成/卡住状态和撤销历史。动画位置、选中瓶、临时消息和未完成搜索不保存。

合法动作先提交逻辑状态，再播放动画；React 提交后异步保存，并在切后台重试最新快照。写入按序执行，旧的慢写不能覆盖后来的新局面；成功的同一快照不重复写。写入失败在菜单中提示，更改进度或切后台后重试。强制结束进程可能发生在异步写入完成前，不能保证恢复最后一瞬间尚未落盘的操作。

恢复前锁住游玩界面，防止启动新操作与读盘竞争。存档检查格式、字段、长度、实际关卡与当前基线的绑定、动作合法性、ID 与节奏计数；只回放规则，不运行求解器。当前最多恢复 4096 个动作，输入最多 128 KiB。超长会话保留内存游玩，明确提示未保存。

读取失败、内容基线不匹配或记录损坏时显示原因、回到初次体验；不会只因启动或切后台立即用空白记录覆盖旧内容，新的明确操作才建立新记录。当前预发布维护一套基线，不实现旧试验迁移；未来已发布内容更新需要另行确定跨更新存档策略。
