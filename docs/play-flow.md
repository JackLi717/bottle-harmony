# 千关主线与本地进度

更新日期：2026 年 10 月 7 日。

当前应用已接入一千道固定编号的实际题目，按[制作配方](production-plan.md)每十关起伏。首三关是两至三色教学，之后普通题优先采用重叠的多色范围；收尾按实际规划难度递增，不按颜色数判难。四档配额为轻松 300、标准 300、思考 305、挑战 95。

## 主线与重玩

从第一关开始，完成后“下一关”解锁下一题。未解锁关卡不可选择，主线没有跳过；撤销、重来、演示一步免费。应用冷启动先进入独立主页，点当前 `Level N` 入口才进入游玩并恢复原来的局面与撤销记录。游戏页返回或 Android 系统返回回到主页；页面位置不写入存档。主页提供当前主线、选关和全局设置，选关菜单显示已通过数量与已过关重玩。选关用五列虚拟列表，不一次挂载一千个按钮，打开时定位当前关卡。第一千关完成后显示主线完成，可选择已通关题，不生成第一千零一关。

完成记录不会因撤销或重来抹除；但当前主线仍保留实际动作历史。重玩有独立局面、动作和撤销历史，进入重玩不会替换尚未完成的主线。“回到主线”或菜单“继续主线”恢复原来的待完成局面。

## 内容与评级

assets/levels/mainline-catalog.json 保存 1000 个固定编号、实际布局、生成来源、完整参考解法、结构键、八级策略证据和固定负担分。制作以实际评级收题，不修改档位凑数，全部来源重建、逐步回放、全球结构去重和独立重算通过后接入。

assets/levels/mainline-play.json 是完整已验收内容的精简投影，保存编号、实际布局、参考路线、内部级、用户档和分数。应用启动只验证此投影的规则、路线、编号、结构唯一与配方；完整策略证据在内部调试打开时延迟加载，手机不运行完整评级。制作验证要求逐条与完整记录一致。

提示优先匹配参考路线上的实际局面，偏离后使用有状态和时间预算的增量求解。搜索达到预算时以短弹窗说明本次未及时找到，不宣布高难或无解；游玩过程不常驻提示语。五色以内默认 BFS，更大局面使用 A*；已找到的路线必须完整回放。

## 卡住时的恢复

未完成且当前没有合法倒水时，底层会话状态为 `stalled`；最后一次倒水回位后，底部工具区显示轻量提醒“暂时没有可倒的瓶子”，提供免费撤销一步、重新开始及关闭。提醒覆盖原有工具区空间，不改变瓶身大小和坐标。关闭后保留局面，同一局面不重复弹出；连续撤销若仍卡住可继续撤销，不连环提醒。返回主页不弹提醒，再进入恢复的卡住局面时提示一次。减少动态效果时直接显示。

仍能操作但提示求解完整耗尽并确证无解时，显示区别于无合法移动的“这个局面无法完成”，提供相同恢复入口；搜索超预算或取消只说明本次未找到解法，不判失败。没有空瓶不是卡住条件，瓶塞不增加禁倒规则。提醒只属于 UI，不写入存档、不扣生命、不改变解锁，也不在每次操作后启动完整求解。方案及判定边界见[卡住局面提示方案](stalled-board-design.md)。

## 当前本地保存

AsyncStorage 键为 bottle-harmony.mainline.v1。保存当前关号、连续已完成位置、主线与重玩两个起始题 ID 和合法动作序列、教学状态及辅助符号偏好。不保存动画、选中瓶或搜索状态。动作先提交逻辑状态，再异步按序写入；切后台结束视觉动画、保留已接受的逻辑动作，并重试最近的保存。

读盘结束前锁住游玩入口。恢复逐步回放并恢复撤销历史，严格检查当前内容 ID、编号、解锁顺序、主线/重玩绑定和动作合法性。两个局面各最多 4096 个动作，保存最多 256 KiB。超长或写入失败在菜单说明，保持内存游玩并重试。强制结束进程仍可能早于最后一次异步落盘。

当前预发布只有这一套主线基线；此前自由试玩存档不迁移为通关记录，初次升级会提示从第一关开始。读取失败或损坏不会在挂载时立即覆写已有存储，新的明确操作才建立新记录。数据本机保存，无账号、云同步和上传。

## 视觉与内部工具

大众游玩界面采用墨黑渐变底色与柔和光感（无拱廊、金线或简笔画装饰），搭配薄边玻璃按钮和现代线条图标。瓶身比此前宽瓶收窄约 9%，高度和同屏统一尺寸保持不变；玻璃内部与倾斜液体体积模型一并匹配。主页展示品牌、当前关卡入口、选关入口与全局设置。游戏页只展示返回按钮、`Level N`、瓶子和撤销/提示/重来三个工具，去掉设置、难度、颜色完成进度、倒水次数、常驻指导文字与庆祝标题。免费提示仍执行一步合法参考操作；普通操作的说明仅供读屏，实际搜索失败才弹出说明。首次教学在第一次点击关卡入口后出现，不遮住启动主页。

实际整关完成、倒水回位并等待最后瓶塞收尾后，直接在原有瓶子区域叠加透明礼花。棋盘、瓶塞、背景与布局保持原样，没有独立卡片、遮罩或庆祝标题。D1/D2/D3/D4 分别升空 2/3/4/5 朵礼花，每朵包含六种颜色、三层大小错落的花瓣与延迟碎星，共 180 条火花；发射减速，绽放扩散，长尾随阻力与重力弯曲下落并熄灭。按颜色合并各层 SVG 路径，不为每条火花创建原生视图。礼花数量使用已验证难度，不是新增评分。配套原创合成的发射、绽放与余响，主页设置可关闭，偏好独立保存在 `bottle-harmony.sound.v1`。默认开启，iOS 遵循系统静音，不录音、不后台播放。

倒水声采用 JohnsonBrandEditing 的 CC0 实录《Water Pour》剪辑，随可见水流的同一 UI 动画时钟开始与停止，不在选瓶、提瓶、回位或非法操作时播放。现有倒水动画为 1900 毫秒，水声覆盖水流出现到尾部渐隐的约 0.769 秒。素材预加载一次，每次倒水从头播放；音效关闭、切后台、窗口变化和动画取消会停止播放，并使未完成的异步准备失效，防止事后补播。减少动态效果时动作瞬间完成，不额外播放延迟水声。倒水与礼花共用已有音效开关及本地偏好，没有新增设置项。安卓原生按键音沿用手机系统设置，不增加应用内按键音开关、不修改系统设置。素材来源、许可与可复现剪辑方法见 `assets/audio/README.md`。

礼花落尽后，同一游戏页的继续按钮淡入；按钮区始终保留高度，不挤压棋盘。返回、撤销、重来可提前终止庆祝；切后台或窗口变化也结束动画、释放音轨，回来显示当前局面和继续按钮，不重播。减少动态效果时跳过礼花并直接显示继续；载入已完成局面、重新进入或冷启动不自动重播。普通主线继续下一关，重玩或内部预览返回主页，第一千关进入已解锁选关。逻辑完成、解锁与存档在动画之前提交，视觉计时不参与进度。内部四档礼花预览通过真实验证路线重放到独立完成局面，不修改待完成主线或保存预览。主页设置保留语言、音效、辅助符号、完成效果与内部工具；不新增背景音乐、其余音效、震动或新玩法。

四至十二瓶使用两排，每排最多六瓶。较大棋盘扩展可用横向空间并增加独立触摸区域，小屏六列保持至少 44 点且不重叠。十一色各有独立名称和配色，可在菜单切换辅助符号；符号与颜色关联，不固定于瓶子，不改变规则。

主线、重玩和内部预览的四至十二瓶统一使用同一瓶身尺寸，不再随瓶数增加而缩小。棋盘使用整屏宽度，按每排瓶数均匀铺开；六瓶时玻璃轮廓靠近屏幕两边，仅保留小空隙。小屏仅为静止棋盘可用高度缩放，不预留动画余量来缩小瓶子。触摸区域以瓶身中心对齐，和相邻区域不重叠。倒水时允许源瓶水平越过屏幕边缘，超出部分由屏幕裁切；目标瓶固定，瓶口和水流保持对齐。瓶子绘图按视觉槽位复用，切关只更新位置与液体；逻辑瓶子 ID 仍属于各自关卡。固定渐变定义与舞台背景复用，避免下一关卸载并重新创建整组 SVG 与动画绑定。

完成效果属于每瓶自身的状态：只有同色且四层装满的瓶子显示；其他瓶子倒水不隐藏已完成瓶子的效果。接水瓶在可见液体填满后显示，撤销或重来随局面恢复。主页设置提供“完成效果”，提供金边、瓶塞、光环三种并排预览和手动切换，主线与内部预览共用。用户本轮明确要求先比较视觉、暂不锁住；瓶塞当前不禁止选中或倒出，不修改游戏规则和离线评价，也不随机分配。试选仅保留在当前运行中，重新打开应用默认瓶塞，不改保存格式。完成时新增约 1.2 秒的柔和光晕、两道扩散光圈和六个错时闪亮的亮点，瓶塞从瓶口上方落下、轻压后回弹落定。瓶塞为完整的锥形软木塞，下半段伸入瓶颈，透过玻璃可见；前侧瓶口遮住交界处，玻璃色泽和反光覆盖插入部分。仅本瓶从未完成变为完成时自动播放；其他瓶子的倒水、普通重绘、切关、恢复已完成局面不重播。比较页可手动“重播完成动画”。动画在 UI 线程执行；切后台、窗口变更、撤销或开启减少动态效果时取消并显示当前局面的稳定效果。动画不控制完成判定、操作提交或存储。

用户的内部构建在“设置 → 开发工具”保留调试难度、C 对照题、原始体验，以及十一色十二瓶、十色十二瓶和第 1000 关的内部预览。这些预览不解锁、不记通关、不覆盖主线，也不保存为主线。关闭后在主页点击当前关卡继续主线。

app.json 的 extra.internalTools 控制内部入口。当前安装版为 true，正式界面可置 false 隐藏内部工具。没有新增每日题、计时、体力、广告、付款或额外瓶道具。

## 生产与验收命令

```sh
npm run mainline:build -- --max-candidates 1000000
npm run mainline:verify -- --input builds/mainline-catalog.json
npm test
npm run typecheck
npm run lint
```

制作断点位于本机 builds/mainline-checkpoint.json，保存固定候选地址、接纳的实际记录、预算、提案方式变化边界和拒绝统计。时间超限停在当前候选，工作/状态预算不足拒收且不贴高档标签；已有成品输出在失败时保留。全部配额齐才写成品，独立重验完成才导出精简包。

目前 1000 题来源/回放/评级重算已全部通过。自动检查覆盖顺序解锁、最终结束、已完成记录、主线/重玩独立恢复、错误存档拒绝、十二瓶全部倒水几何、小屏触摸区域、辅助符号偏好及完整/精简内容对应。安装和手机检查记录见[设备说明](device-testing.md)；持续试玩、帧率、发热、耗电与各设备定量预算另需实测。

公众界面支持 English、简体中文、繁體中文、Español、Português、Français、Deutsch、日本語、한국어、Русский、العربية、हिन्दी 和 Bahasa Indonesia。语言列表第一行永远显示各语言自己的名字，第二行显示当前界面语言中的名称；顺序固定，“跟随系统”固定在滚动列表外，主页设置的语言入口使用地球图标，便于误切后找回。默认按设备首选语言列表匹配，不支持的语言回退英文；设置中可即时切换并记住选择。偏好独立存于 `bottle-harmony.language.v1`，不修改主线存档。阿拉伯语正文及导航行按 RTL 显示，游戏坐标保持固定；原生自动镜像关闭，避免棋盘或菜单双重翻转。关卡标题保留 `Level N`；辅助标签、颜色读屏、教学与保存状态均翻译。内部校准对照和诊断报告保留中文技术文本。
