## 安卓安装

构建完成后的独立测试包位于 `builds/bottle-harmony-demo.apk`。通过 USB 连接手机，开启开发者选项和 USB 调试，授权这台电脑后安装：

```sh
adb install -r builds/bottle-harmony-demo.apk
```

也可以把 APK 传到手机，从文件管理器打开并允许该来源安装。包内包含游戏脚本，打开和游玩不需要电脑、Metro 或联网。它使用开发测试签名，不能作为正式发布签名使用。

重新构建需要 Node 24、JDK 21、Android SDK，以及 `ANDROID_HOME`：

```sh
npm run android:apk
```

原始构建产物在 `android/app/build/outputs/apk/release/app-release.apk`。

## iPhone 安装

iOS 真机安装需要 Apple 开发签名和设备授权；模拟器 `.app` 不能直接安装到 iPhone。

连接 iPhone 并信任电脑、启用开发者模式，在 Xcode 中打开生成的 `ios/BottleHarmony.xcworkspace`，为 BottleHarmony target 的 Signing & Capabilities 选择自己的开发 Team，然后执行：

```sh
npm run ios:device
```

使用 Release 配置，脚本打入应用，不依赖 Metro。免费 Apple ID 通常可用于个人设备的短期开发测试；实际签名限制由 Apple 账号与 Xcode 决定。TestFlight 分发另需 Apple Developer Program 与上传流程，当前没有上传或发布。

## 测试顺序

1. 首次打开：主页品牌、当前关卡、选关与设置完整显示；点关卡后首次教学出现，进入游戏后只有返回、关卡号、瓶子与三项工具，没有被系统栏挡住。
2. 点有水的瓶子：瓶子抬起；再点同一个瓶子取消选择。
3. 点空瓶：观察移动、倾斜、水流、液面变化和回位，颜色层数保持正确。水流应从源瓶口连续接入目标瓶内液面；逐渐倒空时倾角会加大。
4. 点顶部异色或满瓶：不改变液体；读屏可获知原因，游玩页不常驻说明文字。
5. 连续快速点击：同一时间只接受一次倒水，结束后继续操作。
6. 撤销、重来、提示均正常；连续提示可以完成当前局面。返回主页再进入和冷启动后进入同一关，局面与撤销记录保持。
7. 倒水过程中切后台再回来：显示该次已接受操作的结果，没有悬空瓶或错误数量。
