## 兼容范围

- Android 最低 7.0（API 24）；目标 Android 16（API 36）。旧设备安装下限与商店目标版本是两个独立设置。包含 arm64-v8a 和 armeabi-v7a，覆盖常见的 64 位与 32 位 ARM 手机。
- iPhone/iPad 最低 iOS/iPadOS 16.4，这是当前 Expo 57 / React Native 0.86 的支持下限。4.7 英寸 iPhone 8、SE 第二/第三代等满足系统要求的设备可作为测试对象；iPhone 6、6s、7 等不能因为屏幕大小相同就视为支持。
- 手机竖屏；棋盘按可用宽高等比例缩放，刘海和系统底部区域单独避让。平板放大棋盘，没有额外平板玩法；当前保留 Expo 的 iPad 多方向支持，棋盘在宽窗口中仍保持竖向比例。
- 安装成功不等于性能合格。旧手机的流畅度、温度和耗电必须在真机检查。

## 安卓安装

构建完成后的独立测试包位于 `builds/bottle-harmony-demo.apk`。通过 USB 连接手机，开启开发者选项和 USB 调试，授权这台电脑后安装：

```sh
adb install -r builds/bottle-harmony-demo.apk
```

也可以把 APK 传到手机，从文件管理器打开并允许该来源安装。包内包含游戏脚本，打开和游玩不需要电脑、Metro 或联网。它使用开发测试签名，不能作为正式发布签名使用。

重新构建需要 Node 24、JDK 21、Android SDK，以及 `ANDROID_HOME`：

```sh
npm run android:apk
```

原始构建产物在 `android/app/build/outputs/apk/release/app-release.apk`。

## iPhone 安装

iOS 真机安装需要 Apple 开发签名和设备授权；模拟器 `.app` 不能直接安装到 iPhone。

连接 iPhone 并信任电脑、启用开发者模式，在 Xcode 中打开生成的 `ios/BottleHarmony.xcworkspace`，为 BottleHarmony target 的 Signing & Capabilities 选择自己的开发 Team，然后执行：

```sh
npm run ios:device
```

使用 Release 配置，脚本打入应用，不依赖 Metro。免费 Apple ID 通常可用于个人设备的短期开发测试；实际签名限制由 Apple 账号与 Xcode 决定。TestFlight 分发另需 Apple Developer Program 与上传流程，当前没有上传或发布。

## 测试顺序

1. 首次打开：标题、四瓶、说明和底部按钮完整显示，没有被系统栏挡住。
2. 点有水的瓶子：瓶子抬起；再点同一个瓶子取消选择。
3. 点空瓶：观察移动、倾斜、水流、液面变化和回位，颜色层数保持正确。水流应从源瓶口连续接入目标瓶内液面；逐渐倒空时倾角会加大。
4. 点顶部异色或满瓶：出现简短说明，不改变液体。
5. 连续快速点击：同一时间只接受一次倒水，结束后继续操作。
6. 撤销、重来、演示一步均正常；连续演示可以完成演示局面。
7. 倒水过程中切后台再回来：显示该次已接受操作的结果，没有悬空瓶或错误数量。
8. 连续玩 10–15 分钟，记录明显掉帧、发热、耗电和误触。此步骤需要真机，模拟器无法代替。
9. 分别检查向左、向右、同列、从下排往上排倒水：源瓶的瓶口与瓶底全程可见，不能被点击区域裁掉；目标瓶始终保持原位。倒入上排瓶子时，源瓶可经过标题区域，上方系统栏仍应避让。
10. 安卓重点检查：点选上排源瓶时抬起正常，再点目标开始倒水时不能先下落、回弹或闪跳；同时比较下排源瓶。iPhone 保留相同的轻微抬起反馈。使用“演示一步”时，未选中的源瓶也应从原位连续抬起。

系统“减少动态效果”开启时采用直接状态切换。记录测试时该设置是否开启。

倒水几何检查覆盖四瓶之间全部 12 种方向、1–4 层余量以及移动/倾斜/回位的连续采样，检查完整旋转矩形保持在屏幕可用区域（含棋盘上方留白）内、源瓶口对准固定的目标瓶口上方。检查选中与未选中两种起点，以及各动画阶段的连续性。实际显示仍需要原生录屏确认：瓶子始终留在同一个绘图组件，点击区域独立，避免倒水开始时重建视图。

修正后使用棋盘绝对坐标定位与原生默认中心旋转，绘图、边界计算和瓶口位置共用同一旋转中心。4.7 英寸 iPhone SE 模拟器逐帧录屏已确认上排向同列下排倒水时，源瓶在移动、倾斜、倒水和回位中完整可见，水流接到目标瓶内液面。[倒水过程截图](previews/pour-iphone-se.png)。其他方向已有几何检查，仍可在两台真机继续检查手感。

保持目标瓶固定后，iPhone SE 模拟器通过合法操作清空上排第一瓶，再将下排第三瓶的两层珊瑚红倒入其中。原生录屏确认目标瓶位置不变、源瓶可使用副标题区域的空间，瓶子与水流完整可见并正常回位。[倒入上排截图](previews/pour-into-upper.png)。7 项规则与几何测试、类型检查、ESLint 均通过，两个平台的 Release 更新已安装并启动。

当前瓶子始终保留同一绘图组件，使用统一绝对定位，从实际选中高度开始移动，并在视图提交后启动动画时钟。用户在最新真机复测中认可当前效果与速度，并认为核心技术问题已经解决。结合此前 iPhone 和低端安卓手机的试玩反馈，当前视觉演示的真机体验验证通过；此结论来自实际试玩反馈，未进行帧率、功耗等定量测量。

推荐记录：型号、系统版本、屏幕截图或录屏、卡顿出现的操作、测试时长。正式性能结论以独立 Release 构建为准。
