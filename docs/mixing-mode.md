# 调色内部试验

更新日期：2026 年 10 月 10 日。当前已实现 mixing-six-v1／mixing-pairs-v1 六题，仅显式开启内部工具的构建提供“设置 → 开发工具 → 调色试验”。本文是已实现调色规则、题目与保存的唯一正文；公开入口、正式题量、扩色及更精细作品是[后续设计](gameplay-ideas.md#扩色与成果精细化待评审)，尚未实施。

## 当前规则

调色实验室对应创意 151，花朵／彩虹成果对应 152，是同一玩法的成果模板。原料可直接从瓶顶取用，埋住时才需要在普通瓶间周转，不要求先整理全盘。

| 项目 | 当前行为 |
| --- | --- |
| 普通瓶 | 四份容量，顶部连续同色按余量转移 |
| 调色杯 | 两份容量，每次倒入一份；杯空可自由选择未完成目标，已有原料时目标锁定 |
| 混合与收集 | 两份自动混合；逻辑颜色与两份液量符合当前目标才自动收集、清杯并选择下个目标 |
| 完成 | 全部目标交付即完成，不要求原料用尽或剩余原料全盘归类 |
| 错配 | 留在杯中，可免费撤销或按同色／余量规则倒回空瓶／兼容瓶；生成色不能再次调配 |
| 撤销与重来 | 撤销整次玩家倒水及其混合／收集／完成；选择目标不单占一步；重来恢复本题全部原料 |
| 守恒 | 一份加一份得到两份，原料身份与批次稳定，无丢弃、补料、惩罚或收费 |
| 成果 | 按有效交付顺序逐色注入花朵／彩虹模板，不需手工填色或按最终色带顺序调色 |

原料为红、黄、蓝、白。确定游戏配方：红黄→杏橙、黄蓝→鼠尾草绿、红蓝→丁香紫、红白→玫瑰粉、蓝白→晴空蓝、黄白→奶油黄；同色相加不改色。不宣称真实颜料模拟，验收依稳定配方／颜色 ID，不比较 RGB 距离。

彩虹杯是成果展示，不是后续有序配方的现场目标杯。当前调色不叠加记忆黑块、不改变经典十一色或主线／记忆／钱包。十五款玻璃仍是免费外观，渲染可传入独立配色与符号。

## 六道体验题

每题两个空周转瓶，三个彩虹与三个花朵。第 1、4 题是相同布局／任务的表现对照，不计作两道结构互异题。

| 编号／稳定 ID | 任务 | 观察重点 |
| --- | --- | --- |
| 1／lab-rainbow-01 | 杏橙、鼠尾草绿各两份，原料直接可取 | 混色与自动收集 |
| 2／lab-rainbow-02 | 橙绿，取料受阻，有一份余料 | 自然周转 |
| 3／lab-rainbow-03 | 橙、绿、紫各两份，直接可取 | 增加目标后的节奏 |
| 4／lab-flower-01 | 与第 1 题相同任务，花朵模板 | 同任务不同成果 |
| 5／lab-flower-02 | 紫、绿各两份，需要周转，有一份余料 | 空间与取料顺序 |
| 6／lab-flower-03 | 粉、绿、奶油黄各两份，需要周转 | 白色原料与自由目标顺序 |

## 实现与恢复

src/game/mixing.ts 管理原料／批次、容器、配方、交付与整步撤销；mixingCatalog.ts 保存固定六题。src/art/MixingArtwork.tsx 只读有效成果，用真实目标色呈现作品；撤销成果不会进入作品。收集与完成先提交，倒水、混合和约三秒注色仅表现结果，可直接显示完整作品。返回、撤销、重来、后台、窗口变化或减少动态效果取消表现；恢复已完成局面不重播。

mixingRepository.ts 在玩家 SQLite 四张 mixing_trial_* 表独立保存，按稳定题目 ID 恢复当前局面、目标、交付顺序及最近 256 步撤销，共用串行事务。恢复校验份数、来源、批次和历史；损坏显示错误，不清库、不导入旧原型或迁移开发存档。新增文案仅中英，其余语言回退英语。

## 已验证与后续边界

六题离线有界 BFS 与独立回放、守恒、自动收集、错配退回、禁止成品再混、目标选择、重来和 SQLite 恢复／失败重试已有回归。浏览器英／中／阿拉伯不同尺寸完成六题、撤销与刷新恢复通过；内部 Release 曾安装双机并启动，真机完整操作与持续性能未全面验收。证据见 builds/mixing-trial/ 和[设备支持](device-support.md)。

当前没有公开编排、自由比例、三色混合、成品再混或 256 色库。是否公开独立入口、穿插经典／副关、扩充配方与作品、正式规模和权益仍待评审；不能把六题原型的验证当作正式内容趣味或手机性能结论。
