## 维护规则

1. 改功能时同步责任文档；基线和索引只摘要、链接，不复制完整规则。
2. 讨论形成方案后用最终方案替换过程；明显过时、重复的文档直接删除，不建档案、旧版本副本或跳转占位文件。
3. 已确认未实施与待讨论分开；候选不等于第二版范围。新文档仅用于已有文档无法承载的独立主题。
4. 版本来自配置与运行资产；发布状态注明用户确认或 Console 证据。源码检查、构建、模拟器与真机验收各自说明范围。
5. 诊断报告按需生成到忽略的 `builds/`，不覆盖产品文档；素材许可、当前发布产物标识和必要验收依据保留。
6. 当前 SQLite 新基线不兼容旧开发数据，具体边界见统计方案；真正开始玩家测试后须保护新基线进度。不为未上线实验增加迁移或档案。
