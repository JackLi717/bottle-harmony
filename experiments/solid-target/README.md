# 瓶底凝固目标瓶：结构与样题实验

日期：2026-10-07。此目录保留离线制题证据；从这里筛选的 50 道副关卡已另存入 `assets/levels/solid-side-50.json`，接入手机玩法，但不替换原千关主线。

## 规则与材料

目标瓶仅最底一层凝固；其余液体按现有规则倒出。凝固层不能倒出，但目标瓶仍可按普通同色规则接收液体。对照状态是把这一层加热恢复流动，开局排列、颜色、容量和瓶数均不变。两种状态都用普通全瓶同色作为通关条件。

`20-candidates.json` 包含 20 道新生成的四至六色题，7 道四色、7 道五色、6 道六色。每题恰好一个开局空瓶，另有部分装水瓶；目标瓶也是部分装水瓶，列在最后，`frozenBottle` 为其索引。瓶中每种颜色最多两层；所有开局满瓶至少三色。每题保存双状态的最短路线，路线分别按对应规则完整回放。

运行 `node --experimental-strip-types scripts/solid-target-prototype.ts` 可用固定种子重新生成 20 题和求解证据。运行时若某题或某个开局分支的搜索超过 300,000 状态或 5 秒，该结果只能记为未知；本次 20 题和全部开局分支均未超限。受限求解保留目标瓶身份，其余瓶可按结构交换；启发式下界为颜色段数减颜色数。

## 结果

| 检查 | 结果 |
|---|---:|
| 接纳 20 题所试排列 | 33 |
| 凝固、加热都可解且路线已回放 | 20/20 |
| 凝固比加热最短路线更长 | 0/20 |
| 开局凝固状态的高成本绕路或死路 | 0/171 个合法倒法 |
| 开局加热状态的高成本绕路或死路 | 0/171 个合法倒法 |

开局风险按原 `human-decision-v1` 的决策后果口径区分：比最短路线多 0–2 步视为可恢复，至少多 3 步为高成本绕路，完整求解无解为死路。这只是首步检查，不是完整的人类难度评分。

`existing-challenge-audit.json` 是补充对照：从现有主线选出 20 道四至六色、单空瓶、原风险分较高且瓶底凝固后仍可解的题，分别检查最短路线的开头、约三分之一、约三分之二处。凝固与加热的最短路线全部相同。60 个观察点合计，加热有 217 个合法倒法，其中 115 个可恢复、102 个死路；凝固有 213 个，其中 111 个可恢复、102 个死路。只有 4 题各少了一个安全倒法，没有新增死路。运行 `node --experimental-strip-types scripts/solid-target-prototype.ts --analyze-existing` 可重算；这是对照分析，不是另 20 道新题。

另用固定种子搜索 4,794 个带真实空瓶、其余空容量分散在部分装水瓶的四至六色局面，逐一凝固非空瓶底层，共检查 28,827 个变体；两种状态全部可解，无搜索未知，凝固后最短路线增加的变体为 **0**。该大样本只检查最短步数，没有逐题测量完整决策风险。

## 反向构造与完整小规模枚举

`scripts/solid-target-prototype.ts --reverse-construct` 从已完成的、目标瓶底层固定的局面出发，逐步反推前驱。每一步都检查它在正向是否真的是合法的最大倒水，所以得到的开局天然有一条凝固状态解法。筛除开局满瓶单色、任一瓶同色超过两层后，四、五色的一空瓶容量组得到 653 道、两空瓶容量且至少一只真实空瓶组得到 704 道；这 1,357 道中没有加热前后的最短步数差。记录在 `reverse-construction-audit.json`。

反向构造保证**有解**，不能保证它的构造路线是最短路线，更不能保证加热能明显缩短路线。`--optimize-gap` 从已有的“凝固多两步”局面开始，局部调整颜色和余量；17,747 个合规且双状态可解的邻近局面没有把差距提高到三步。这个起点没有真实空瓶，不能直接充当当前主线关卡。记录在 `gap-optimization-audit.json`。

`scripts/solid-target-exhaustive.ts` 对三色、四瓶、总空容量为一瓶的**全部可达结构**分别按普通和凝固规则做反向广度优先搜索，结果在 `exhaustive-three-color.json`。凝固仍可解的 41,932 个结构中，只有 12 个比普通规则多一步；它们都没有真实空瓶。有一只真实空瓶的 4,420 个结构，步数差全部为零。这是该尺寸的完整枚举结论，不可直接推广为所有颜色数的定理。

制题条件应写成“双状态差距”：同一开局在凝固状态可解，且凝固状态的最短路线或决策风险显著高于加热状态。只写一条较长的参考路线不能证明玩家必须那样玩。

## 新结构：空位分散，没有整只空瓶

`scripts/solid-target-exhaustive-variants.ts` 用完整状态图比较三色四瓶、总空容量四格的结构。开局有一只完整空瓶时，单层凝固、同瓶双层凝固、双瓶各凝固一层都没有产生首步风险增加；没有完整空瓶时，单层凝固的 24,583 个合规可解结构里，有 410 个首步危险选择比例高于加热状态，其中 180 个高出至少 0.5。具体统计见 `exhaustive-variants.json`。双层和双瓶方案在这一尺寸也有少量风险差，但无需靠它们才能形成有力样题。

`risk-gap-20.json` 从完整枚举中选了 20 道三色题，保留目标瓶身份，对换色和普通瓶调位去重；十道目标瓶开局两层、十道三层。每题凝固和加热均有精确最短解与首步后果。它们**没有整只空瓶**，但总空容量仍是四格，分散在几只瓶里。此布局超出当前主线“开局一或两只空瓶”的制作范围，是待讨论的新关卡结构。

`scripts/solid-structure-research.ts` 尝试三种构造方法：从凝固完成图反推、从不同颜色的加热完成图反推、直接安排凝固底层和分散空位。仅增加凝固层数或瓶数，未稳定增加最短步数；没有整只空瓶且保留单层凝固时，风险差更明显。`--lift-risk20`、`--lift-five`、`--lift-six` 从已验证的陷阱题中替换四个旧颜色层为一种新颜色，把被替换的四层移进新增瓶子。这样每色仍恰好四层、总空容量仍四格，局部空间依赖得以延续。每次升色后重新完整求解两种状态和所有不同的首步，不沿用母题评级。四色得到 15 个、五色 42 个、六色 127 个符合“加热无死路、凝固至少两个首步死路且危险比例差至少 0.5”的候选；这三个数是原始合格候选数，不是全局结构去重后的关数，详见 `lifted-*-color.json`。

`constructed-20.json` 从三、四、五、六色各选五道结构不同的题，并保存双状态路线。`scripts/solid-structure-assemble.ts` 再次检查颜色守恒、开局质量和路线回放。`--validate-constructed20` 由另一套逐题求解重新计算最短步数及首步后果；`--analyze-constructed20` 检查错误首步是否表面上仍合并颜色段。结果：

| 同一批 20 题 | 加热状态 | 底层凝固状态 |
|---|---:|---:|
| 开局不同选择 | 72 | 72 |
| 两步以内可补救 | 72 | 20 |
| 确证死路 | 0 | 52 |
| 凝固最短解比加热多一步 | — | 2 题 |

52 个死路首步**全部**表面上减少颜色段数。给这 20 题各补一只完整空瓶后，两种状态合计各有 182 个首步选择，全部可补救，死路归零；见 `constructed-20-validation.json` 和 `constructed-20-decisions.json`。这说明难度差来自“空位被颜色限制、没有通用中转瓶”，不是单靠液体层数或最短步数。

## 制作判断

原本有完整空瓶的 20 题没有显示预期效果；**没有完整空瓶、空容量分散**的结构已经构造出可验证的显著决策差，并扩展到六色。它目前只是离线原型，不直接替换主线：现有主线制作配方和导入筛选要求一或两只空瓶，真人是否会把这些陷阱感受为“有趣的思考”还是“开局猜错就死”也尚未检验。用户已接受这种新结构；下一步做小规模可玩试玩与难度校准，在此之前不批量重编千关。

## 已确认的设计方向与试玩门槛

用户已接受“开局没有整只空瓶、但四格空容量分散在瓶中”的关卡结构，并明确指定另加 50 道副关卡，每 20 道原主线后出现一题。`seed-pool.json` 从完整三色枚举保存温和候选；`scripts/solid-structure-research.ts --assemble-side50` 从三色候选和四色至六色构造池选出 10/12/14/14 道，形成独立运行包。每题凝固与融化都可解，双状态路线和首步后果重算，目标瓶身份参与结构去重。`constructed-20.json` 仍是压力测试样题，不直接作为二十道连续正式关卡。现有风险梯度未经真人校准，下一步在手机上试玩并观察融化使用率。

试玩原型建议允许玩家随时免费加热，立即恢复普通倒水规则；重来恢复原始凝固状态。加热后的完成照常推进，不用提示券或金币作为退路门槛。观察玩家是否能从瓶底和可用空间推断正确准备步骤，以及重来、提示、加热和放弃的原因。如果多数人只是随机试首步，先减弱陷阱或降低出现频率，不把高死路比例直接等同于有趣的高难度。
