# Audio sources

## Water pouring

`water-pour.wav` is an edited excerpt of **Water Pour** by **JohnsonBrandEditing**:

- Author page and license: https://freesound.org/people/JohnsonBrandEditing/sounds/173930/
- Public HQ preview used: https://cdn.freesound.org/previews/173/173930_3229685-hq.mp3
- License: CC0 1.0 — https://creativecommons.org/publicdomain/zero/1.0/
- Retrieved: 2026-10-07.
- Source SHA-256: `31aad4ba08594f6c70b9d66154e793bb4db5e68001becd06f6f2c4376511efd2`.
- Output SHA-256: `6e7eef3d70692c3540e19ca3b720ebe8bee7f5f61ae97fcf905d8df37008d2d0`.

`scripts/prepare-water-audio.py` extracts the continuous stream at 1.35 seconds,
filters low rumble and very high frequencies, normalizes without clipping, adds
12 ms / 30 ms edge fades, and writes mono 22.05 kHz PCM. The 0.769478-second
file fits the existing 1,900 ms pour animation's visible flow, including its
fade-out. No generated tones or noise are added. The original downloaded
preview is kept in local `builds/` for reproduction, not shipped in the app.

## Fireworks

`fireworks-2.wav` through `fireworks-5.wav` are original deterministic synthetic
launch, burst and crackle effects generated by `scripts/make-fireworks-audio.py`.
They contain no third-party recordings.

Android button clicks use the operating system's own click feedback through
React Native Pressable; no click recording is bundled.
