# 商店截图基线

拍摄日期：2026 年 10 月 8 日。四张沿用 0.1.0（1）发布包中的 `mainline-1000-v5` 题库画面；当前 0.1.1（5）测试提交继续使用它们，本轮未重拍或重新上传。`evidence.json` 的旧包哈希和草稿核对状态只描述拍摄批次，最新发布状态见[发布记录](../../../docs/release-readiness.md)。

这一组图片是产品橱窗：先让人注意到原创容器，再展示清爽体验、内容深度和辨色辅助。当前只选四张有不同作用的画面，不以连续关卡或重复同一棋盘凑数。

| 4 | 910 / 冰晶直杯，开启符号 | 8色、9杯，上5下4 | 展示颜色辅助符号和另一种容器、排面 |

原尺寸图片在 `en-US/`，均为1080×1920、24位PNG。`selection-preview.png` 为按展示顺序排列的缩略对比图；只用于审阅，不上传为商店截图。这组以棋盘为主、没有额外宣传文案的英语截图可作为各语言页面共用素材，不因应用增加语言而复制或重拍。当前已共用到中文页面；图中仍有少量英文按钮和提示券说明。将来若添加宣传标语，再按需要本地化标语。

`scenes.json` 记录每张图的关卡ID、布局摘要、关卡SHA-256、容器ID、符号开关、镜头状态及顺序。`manifest.json` 记录成品图片SHA-256和尺寸；`evidence.json` 绑定拍摄时的AAB/APK。素材进入Git后，版本历史可用于对照更新。

## 重拍与对比

1. 需要更新素材时，选择已有可验证的目标包并在独立截图模拟器安装；当前跨平台适配已实现，平台证据见[设备支持](../../../docs/device-support.md)。不要操作用户真机或数独环境。
2. 用 `scenes.json` 检查新包的内容ID与各关布局摘要。关卡布局变化时先重新选图，不沿用旧图冒充新包。
3. 备份独立模拟器的测试存档。用正式存档解码器验证的临时截图场景进入指定关卡；原图来自实际正式UI，没有内部预览按钮。截图测试记录不代表自然通关经历，也不能用作进度功能验收证据。
4. 使用相同容器、语言与符号开关；四张均停在初始棋盘、未选瓶、无水流/礼花/菜单。音效关闭，完成效果为默认瓶塞（宽口容器自动使用光晕），提示余额4/5，本关免费提示未用。
5. 通过官方adb截图，只移除全不透明alpha；RGB像素必须逐一一致。完成后原样恢复模拟器原存档。当前本地备份、校验器和采集脚本在 Git 忽略的 `builds/play/materials-fixtures/`，不要上传测试数据库到Console。
6. 把新旧画面并排看：容器轮廓、液层、行列、左右边缘、底部按钮、文字、符号，以及整组是否仍能清楚介绍产品。系统时间、电量变化不算产品视觉回归。
7. 通过后更新本目录的四张PNG、预览图、manifest、evidence和Console，保持同一顺序。重拍旧原图留在本地 `builds/play/screenshots-raw/` 供本次对比；正式素材目录只保留当前选定基线。

PC、平板和 TV 适配及本地新截图已有记录，见[设备支持](../../../docs/device-support.md)；新图按用户要求只保存在本地，未进 Git 或上传 Play。本组仍是手机素材，不能拉伸成其他平台截图。
